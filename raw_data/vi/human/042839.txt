Java (phiên âm Tiếng Việt: "Gava") là một ngôn ngữ lập trình hướng đối tượng, dựa trên lớp được thiết kế điển có càng ít phụ thuộc thực thì càng tốt. Nó là ngôn ngữ lập trình có mục đích chung cho phép các nhà phát triển ứng dụng vết một lần, chạy ở mọi nơ (WORD), nghĩa là mã Java điã bên dịch có thể chạy trên tất cả các nền tảng hỗ trợ Java mà không cần biên dịch lại. Các ứng dụng Java thường được bên dịch thành bytecode có thể chạy trên bất kỳ máy ảo Java (JVM) nào bất kể kiến trúc máy tính bên dưới. Cú pháp của Java tương tự như C và C++, nhưng có ít cơ sở cấp thấp hơn các ngôn ngữ trên. Java runtime cung cấp các khả năng động (chẳng hạn như phản ánh và sửa đổi mã thờ gan chạy) thường không có sẵn trong các ngôn ngữ bên dịch truyền thống. Tính đến năm 2019 Java là một trong những ngôn ngữ lập trình phổ biến nhất được sử dụng theo GitHub, đặc biệt cho các ứng dụng web máy khách máy chủ, với 9 triệu nhà phát trển điã điược báo cáo.3.4.2 FrameWork Java Spring boot Spring Boot là một dự án phát triển bở JAV (ngôn ngữ java) trong hệ sinh thái Spring framework. Nó giúp cho các lập trình viên chúng ta đơn giản hóa quá trình lập trình một ứng dụng vớ Spring, chỉ tập trung vào việc phát triển business cho ứng dụng.
