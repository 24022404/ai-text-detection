Tiếp theo là xây dựng phía Server: Cài đặt MySQL va WorkBench điểm xây dựng Database theo thiết kế đã nêu ra ở Chương 4. Cài đặt NetIS bằng npm, sau đó dùng CLO để tạo 1 project NestS. Cài đặt Docker và Docker Desktop để sử dụng Docker trong project. Vết Dockerfile điểm tạo image của project Nest JS trong Docker. Build Docker Image và chạy Container đó. Tiếp theo là bắt đầu xây dựng các API bằng cách kết nối projector với MySQL, vết các Service và Repository điểm xây dựng nghiệp vụ và kết nối với Database, sau đó vết các controller để sử dụng. Cuối cùng là đưa vào Docker compose điểm dễ dàng quản lý.
