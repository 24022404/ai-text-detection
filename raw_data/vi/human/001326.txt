Biểu đồ use case phân rã Quản lý phòng code Hình 2.2: Biểu đồ use case phân rã quản lý phòng code Hình 2.2 là biểu đồ use case phân rã quản lý phòng code. Người dùng có thể xem danh sách phòng code của bản thân, tạo mới một cuộc gặp, chỉnh sửa thông tin phòng code, xóa một phòng code. Người dùng có thể chia sẻ phòng của mình đến những người dùng khác trong hệ thống 2.2.3 Biểu đồ use case phân rã Quản lý danh sách người tham gia phòng code Hình 2.3: Biểu đồ use case phân rã quản lý danh sách người tham gia phòng code Hình 2.3 là biểu đồ use case phân rã quản lý danh sách người tham gia phòng code. Người dùng có thể xem danh sách những người đang tham gia trong phòng, có thể tắt micro của người khác, loại bỏ người khác khỏi phòng code (nếu là chủ phòng).2.2.4 Quy trình nghiệp vụ Hình 2.4: Biểu đồ hoạt động minh họa quy trình chỉnh sửa, chạy, xem kết quả của mã code Hình 2.4 là biểu đồ hoạt động sinh hoạt quy trình chỉnh sửa xem kết quả của mã code.Kh người dùng tham gia vào phòng code, hệ thống truy xuất mã nguồn điã có sẵn và hiển thị nó trên trình soạn thảo.
