Ngôn ngữ CSS CSS là viết tắt của Cascading Style Sheets. CSS là một ngôn ngữ mô tả giao diện cho trang web. Nó được sử dụng để xác định cách một trang web sẽ hiển thị cho người dùng. CSS cho phép người dùng điều chỉnh một loạt các thuộc tính của một trang web, chẳng hạn như màu nền, kích thước văn bản, khoảng cách, và. CSS có thể được sử dụng cho một trang web hoặc cho nhiều trang web vớ một tập tin CSS chung. Sự kết hợp của CSS với HTML giúp tạo ra một trang web đẹp, đơn giản và dễ sử dụng. Ngôn ngữ này cũng có thể được sử dụng vớ bất kỳ loại tài liệu XML nào bao gồm cả XML đơn giản, SVG và XUL.
