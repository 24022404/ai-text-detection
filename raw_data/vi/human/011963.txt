Database trả về cho Modem dữ liệu theo yêu cầu của Model. Model trả về dữ liệu cho Controller xử lý. Controller sẽ gọi điện Vew phù hợp với yêu cầu và kèm theo dữ liệu cho View. View chịu trách nhiệm hiển thị dữ liệu phù hợp với yêu cầu. Sau Khi xử lý hiển thị dữ liệu, View trả về cho Controller kết quả (HTML, XML hoặc JSON. . . ). Sau khi hoàn tất, Controller sẽ trả về kết quả cho Client.  Dựa theo những phân tích biểu đồ use case tổng quan trong chương 1 cho dự án hệ thống hỗ trợ cá nhân, tổ chức doanh nghiệp lựa chọn nhà cung cấp dịch vụ đám mây, cùng cơ sở lý thuyết ở trên, thành phần M trong kiến trúc MVC được xác định là những class: () class Product (xử lý dữ liệu dịch vụ đám mây), () class Vendor (xử lý dữ liệu nhà cung cấp), () class User (xử lý dữ liệu người dùng), (v) class Project (xử lý dữ liệu các dự án), (v) class Requirement (xử lý dữ liệu yêu cầu của dự án), (v) class Question (xử lý dữ liệu câu hỏi đặt ra), (v) class Criteria (xử lý dữ liệu liên quan đến các tiêu chí), (v) class class Advise (xử lý dữ liệu các message kh hỏi chuyên gia), (x) class Comment (xử lý dữ liệu đánh giá)...
