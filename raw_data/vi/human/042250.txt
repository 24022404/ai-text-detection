CSS CSS  – Cascading Style Sheets, là một ngôn ngữ dùng để tìm và đánh dấu các phần tử HTML, giúp tạo phong cách cho trang web như thay đổi bố cục, màu sắc trang web, font chữ, . . . Mố tương quan giữa HTML và CSS là vô cùng chặt chẽ, không thể tách rời. Có nhiều cách sử dụng CSS như () dạng n – mã CSS được nhúng ngay trong thuộc tính style của phần từ HTML, () dạng internal – mã CSS được đặt trong thẻ <style/> của văn bản HTML và () dạng external – mã CSS nằm trong một tệp tin CSS riêng biệt với văn bản HTML, sau đó được gọi đến và sử dụng trong tài liệu HTML.
