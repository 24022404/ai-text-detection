Java  là một ngôn ngữ lập trình và nền tảng máy tính được phát hành lần đầu tiên bỡ Sun Microsystems vào năm 1995.Nó là một ngôn ngữ lập trình hướng đối tượng, dựa trên lớp được thiết kế điển có càng ít phụ thuộc thực thì càng tốt. Java mục đích chung cho phép các nhà phát triển ứng dụng vết một lần, chạy ở mọi nơ (WORD, nghĩa là mã Java điã bên dịch có thể chạy trên tất cả các nền tảng hỗ trợ Java mà không cần bên dịch lạ.
