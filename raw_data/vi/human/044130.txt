Hệ quản trị cơ sở dữ liệu SQL Server  Hình 1.1: Hệ quản trị CSDL SQL Server − Giới Thiệu SQL Server SQL Server là một hệ quản trị cơ sở dữ liệu quan hệ (Relational Database Management System (RDBMS) ) sử dụng câu lệnh SQL (Transact SQL) đi ể trao đi ổ dữ liệu giữa máy Client và máy cà SQL Server. Một RDBMS bao gồm databases, database engine và các ứng dụng dùng đi để quản lý dữ liệu và các bộ phận khác nhau trong RDBMS.rất lớn (Very Large Database Environment) lên đi bến Terabyte và có thể phục vụ cùng lúc cho hàng ngàn user. SQL Server có thể kết hợp “ăn ý” với các server khác như Microsoft Internet Information Server (IIS), Commerce Server, Proxy Server....
