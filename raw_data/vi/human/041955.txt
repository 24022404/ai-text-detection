Có ba góc chính là project, task và models. Gó project chứa các class sau: () project Route – định nghĩa các đường dẫn API cho các thao tác quản lý dự án, () project Controller – xử lý request liên quan đến quản lý dự án và trả về dữ liệu cho client, () protectService – xử lý logic nghiệp vụ bên trong và tương tác với các models, (v) project Phase Route – định nghĩa các đường dẫn API cho các thao Hình 4.4: Biểu đồ gió tổng quan phần client của App QLDA tác quản lý ga đoạn và cột mốc trong dự án, (v) project Phase Controller – xử lý request liên quan đến quản lý các ga đoạn và cột mốc trong dự án và trả về dữ liệu cho client, và (v) project Phase Service – xử lý logic nghiệp vụ bên trong, tương tác với các models. Gó task chứa các class sau: () taskRoute – định nghĩa các đường dẫn API liên quan tới quản lý danh sách công việc, () taskController – xử lý request liên quan đến quản lý danh sách công việc và trả về dữ liệu cho client, và () taskService – xử lý logic nghiệp vụ bên trong, tương tác với các models. Gó models gồm ba phần là () project Model – định nghĩa cấu trúc dữ liệu của dự án, () task Model – định nghĩa cấu trúc dữ liệu của công việc, và () project Phase Model – định nghĩa cấu trúc dữ liệu của một giai đoạn trong dự án.
