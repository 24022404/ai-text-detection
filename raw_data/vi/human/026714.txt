Tương tự như React cho Web, các ứng dụng React Natve được vết bằng cáchsử dụng hỗn hợp đánh dấu JavaScrpt và XMLesque, được gọi là JSX. Sauđió, bên trong, “cầu nối” React Natve sẽ gọi API hển thị gốc trong Objectve C (dành cho OS) hoặc Java (dành cho Androd). Do đó, ứng dụng của bạn sẽ hển thị bằng cách sử dụng các thành phần giao diện người dùng d động thực, không phải webvew và sẽ có gao vện gống như bất kỳ ứng dụng d động nào khác. React Natve cũng hển thị giao dện JavaScrpt cho API nền tảng, vì vậy ứng dụng React Natve của bạn có thể truy cập các tính năng nền tảng như camera điện thoạ hoặc vị trí của người dùng.
