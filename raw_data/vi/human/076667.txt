Hướng xử lý đầu tên là lấy tin nhắn. Người dùng lựa chọn người mà mình muốn nhắn tin, sau đó nhập tin nhắn và ấn gửi. Phía client sẽ gửi một request đến server xử lý dữ liệu và lưu lại tin nhắn. Sau kh điã lưu tn nhắn thành công, server lắng nghe sự kiện này và xử lý dữ liệu gửi response lên WebSocket. Vì sử dụng API để gửi request từ Client lên Server và ngôn ngữ sử dụng ở 2 bên là khác nhau, nên response trả về được viết dưới dạng json điểm bất kỳ ngôn ngữ nào cũng có thể lấy được dữ liệu.
