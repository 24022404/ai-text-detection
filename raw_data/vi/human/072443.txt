Gó "Controller" của module Admin(quản trị viên) chứa các gói Quản lý người dùng, Quản lý bà đi năng, Quản lý phần quảng cáo và Quản lý địa điểm. Gó Quản lý người dùng chứa class như Manage User Controller. Gó Quản lý bà đặng chứa các class PostsController, Add Post Controller, Edit Post Controller. Gó Quản lý phần quảng cáo chứa các class Home Slider Controller và Home CategoryController. Gó Quản lý địa điểm chứa các class Category Controller, Add Category Controller, Ed Category Controller.
