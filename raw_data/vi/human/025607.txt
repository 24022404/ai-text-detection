Tính đến năm 2016, có điến 92% trang web hiện nay đang sử dụng JavaScript.Hình 3.5: Ngôn ngữ javascript Javascript được tích hợp đồng thời nhúng vào HTML để hỗ trợ cho website trở nên sống động hơn. Thông thường, các trang web sẽ được nhúng trực tiếp JavaScript vào, hoặc sẽ sử dụng file .js điểm tham chiếu qua. Đây là ngôn ngữ phía máy khách, nghĩa là thay vì xử lý tập lệnh trên server của trang web, nó sẽ được tải về máy của khách truy cập và xử lý trên chính chiếc máy đó.
