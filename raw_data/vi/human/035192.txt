IDE Visual Studio Code Hình 3.10: Visual studio (nguồn:  Visual Studio Code  (VS Code hay VSC) là một trong những trình soạn thảo mã nguồn phổ biến nhất được sử dụng bởi các lập trình viên. Nhanh, nhẹ, hỗ trợ đa nền tảng, nhiều tính năng và là mã nguồn mở chính là những ưu điểm vượt trội khến VS Code ngày càng được ứng dụng rộng rãi. Chúng tôi đã sử dụng VÀ Code để phát triển code xây dựng giao diện cho người dùng.
