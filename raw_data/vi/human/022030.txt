ExpressJS ExpressJS  là một framework mã nguồn mở, được xây dựng trên nền tảng NodeJS, cung cấp các tính năng mạnh mẽ để phát triển các ứng dụng Web hoac Mobile.ExpressJS giúp tổ chức các ứng dụng web ở phía server thành kiến trúc MVC (Model  View  Controller). Bên cạnh đó ExpressJS hỗ trợ các phương thức HTTP và middleware tạo ra API mạnh mẽ và dễ sử dụng. Nếu không sử dụng ExpressJS, thì lập trình viên sẽ phải thực hiện các bước phức tạp điển xây dựng một API hiệu quả. ExpressJS có thể làm giảm một nửa thờ gần vết mã mà vẫn có thể xây dựng ứng dụng web hiệu quả.
