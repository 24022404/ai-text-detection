RESTful API a, Khá nệm về RESTful API RESTful API là một kiểu kiến trúc phần mềm, được sử dụng để thiết kế các ứng dụng web và các dịch vụ web. RESTful API được xây dựng trên các nguyên tắc của REST (Representational State Transfer), là một phong cách thiết kế phần mềm cho các hệ thống phân tán. RESTful API sử dụng HTTP (Hypertext Transfer Protocol) như một giao thức truyền tải và sử dụng các phương thức HTTP như GET, POST, PUT và DELETE để tương tác với các tài nguyên trên máy chủ.
