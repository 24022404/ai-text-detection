Lưu trữ file trực tiếp trong cơ sở dữ lệu thường không được khuyến khích do vấn đề về hiệu suất và khả năng mở rộng. Cơ sở dữ lệu được thiết kế điển lưu trữ và quản lý dữ lệu có cấu trúc một cách hiệu quả chứ không phải các tệp nhị phân lớn như hình ảnh, video hay file âm thanh. Thay vào đó, cách phổ biến là lưu trữ file này trên file system hoặc các cloud storage service và chỉ lưu đường dẫn file trong database.
