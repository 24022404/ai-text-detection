Spring Framework  là một framework mã nguồn mở phổ biến giúp tạo ra các ứng dụng động lập, chạy trên máy ảo Java (JVM). Mặc dù Spring khá mạnh mẽ nhưng việc cấu hình lạ quá phức tạp. Do đó Spring Boot ra đời giúp việc phát triển ứng dụng dễ dàng hơn. Spring Boot là một công cụ phát triển ứng dụng web và microservice app nằm trong hệ sinh thái Spring Framework. Nó giúp lập trình viên đơn giản hóa việc lập trình ứng dụng vớ Spring, tập chung phát triển tính năng của ứng dụng.
