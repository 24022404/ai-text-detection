fastq_fle: fle gả trình tự gen để dóng hàng path_sam_fle: file lưu thông tin sau khi đóng hàng dưới định dạng file SAM Yêu cầu đầu vào dữ liệu của các công cụ gọi biến thể đột biến cần là file dữ liệu dưới dạng BAM, file nén nhị phân của file SAM. SAMtools là công cụ cho phép chuyển đổi giữa định dạng file SAM sang định dạng file BAM (nhị phân) cũng như sắp xếp lại file BAM dựa trên tọa độ của các gen trong đó chuyển đổi định dạng file SAM thành file BAM. Thông qua 2 câu lệnh bên dưới, ta sẽ thu được kết quả dưới dạng fle BAM điã điược sắp xếp theo thứ tự tọa độ của các gen.
