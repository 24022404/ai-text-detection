Thiết kế tổng quan Sau khi xác định mô hình kiến trúc phần mềm, tô đã xây dựng thiết kế tổng quan thông qua biểu đồ phụ thuộc góc trong hình 4.2. Package views là phần trên cùng của hệ thống được phân chia thành 2 package nhỏ: () package viewer (gồm những class nên quan điến phần view của user), () package webmin (gồm những class nên quan điến phần view của admin). Views sẽ tương tác trực tiếp với người dùng. Người dùng thực hiện thao tác, gửi yêu cầu trên web. Yêu cầu sau đó sẽ điến package Controller, xử lý các yêu cầu của người dùng. Package Controller cũng được chia thành 2 package nhỏ: () package controller User, () package controllerAdmin.
