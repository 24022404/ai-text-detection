Thư mục public chứa file HTML cơ sở và các hình ảnh. Thư mục src chứa các chức năng chính của ứng dụng. Trong thư mục src có các thư mục () common components  chứa các gao dẫn sử dụng thường xuyên nhằm mục đích tái sử dụng, () helpers  chứa các hàm xử lý dữ liệu sử dụng thường xuyên, () lang  chứa file ngôn ngữ nhằm mục đích chuyển đổi ngôn ngữ hiển thị trên giao diện, (v) layouts  chứa các file định hình bố cục của trang web, (v) react routes  chứa các file định tuyến trang web, (v) redux  kho lưu trữ các state dùng trong toàn phần mềm, (v) modules  chứa các chức năng chính của phần mềm. Trong modules có các thư mục () manufacturing  chứa gao vện quản lý sản xuất, () order  chứa giao diện quản lý các đơn hàng.
