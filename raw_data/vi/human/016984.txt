Docker daemon chịu trách nhiệm lắng nghe từ Docker API request quản lý các nội dung như mages, containers, networks, volumes Docker client là cách chủ yếu mà người dùng tương tác với docker bằng các lệnh như docker run, docker images Registry là nơi lưu trữ docker image. Docker Hub là nợ công kha chứa các docker image mà người dùng có thể sử dụng. Mặc định chúng ta sẽ lấy image từ Dockerhub về. Ngoài ra chúng ta có thể dựng registry riêng.
