Luồng dữ lệu của mô hình: Ngườ dùng gử yêu cầu bằng các thao tác trên giao diện, Controller trên OS client sẽ kểm tra dữ lệu từ Model và yêu cầu Model đồng bộ dữ lệu với Server, Controller trên Server sẽ nhận điược request và gao yêu cầu điến Servce tương ứng. Servce truy cập vào Database truy vấn và trả về dữ lệu là các Model Object cho Controller. Controller trên server nhận điược Model Object sẽ trả về cho Clent thông qua lờ gọ API. Model trên OS client Nhận điược dữ lệu sẽ gọ hàm CallBack điến Controller trên OS Clent, sau đió Controller cập nhật giao diện.Hình 4.2: Luồng hoạt động của BackEnd Mô hình ModelVewController (MVC) là một mẫu kiến trúc phân tách một ứng dụng thành ba thành phần logc chính Model, Vew và Controller. Do đió vết tắt MVC. Mỗ thành phần kiến trúc điược xây dựng điể xử lý khía cạnh phát trển cụ thể của một ứng dụng. MVC tách lớp logc nghệp vụ và lớp hển thị ra rêng bệt.
