Context API State là thế mạnh của react nhưng nó cũng đem lại nhiều sự phiền phức. Thông thường các state sẽ được truyền qua các component thông props của component con. Nếu ứng dụng nhỏ thì không vấn đề gì nhưng nếu ứng dụng to và gồm nhiều component thì việc truyền state qua hàng chục component hay truyền state từ 1 nhánh virtual dom này tớ virtual dom khác thì thật là khó khăn. Từ đó các công nghệ điểm quản lý state điã điược snh ra, phải kể đến như Redux, vue, reco, zustand, ... trong số đó phải kể đến Context API.
