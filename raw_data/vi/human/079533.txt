Trong trường hợp muốn thêm các tài khoản hỗ trợ việc quản lý mạng không dây công cộng (do số lượng mạng và các thiết bị quá nhiều), Provider có thể tạo các SAML User. Đố vớ mỗ SAML User trong Workspace, Provider sẽ quản lý giới hạn quyền của SAML User đó. Nếu không còn hợp tác với một tài khoản SAML User nữa, Provider có thể xóa khởi Workspace.a, Biểu đồ phân rã use case Tạo SAML User quản lý thiết bị Hình 2.11: Biểu đồ phân rã use case Tạo SAML User quản lý thiết bị Usecase biểu diễn hoạt động Tạo SAML User quản lý thiết bị của Provide.
