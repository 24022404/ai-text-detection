Ngoài ra, RESTful API còn sử dụng các định danh (URL) điểm định danh và truy cập tài nguyên và sử dụng các định dạng dữ liệu chuẩn như JSON (JavaScript Object Notation) hoặc XML (Extensible Markup Language) điểm truyền thông tin giữa các máy khách và máy chủ với nhau 3.1.3 Tổng quan về HTML HTML là viết tắt của HyperText Markup Language Ngôn ngữ đánh dấu siêu văn bản. HTML xây dựng các nội dung trên trang web dựa trên việc sử dụng các thẻ định dạng (còn gọi là tags). Có nhiều kiểu thẻ tương ứng với từng định dạng dữ liệu khác nhau: hình ảnh, âm thanh, văn bản hoặc các lên kết đến trang web khác.
