Tạ gó Route: Kh một request yêu cầu dữ liệu được gửi tới hệ thống, hệ thống sẽ kiểm tra loại dữ liệu mà request yêu cầu và điều hướng request tớ xử lý ở gò Route tương ứng (ở đây dữ liệu yêu cầu là article nên request sẽ được điều hướng tớ Art leRoute) Tạ gó Controller: dựa vào thông tin request, điều hướng request tớ xử lý được định nghĩa ở gò Repository Tạ có Repository: thao tác với các góc Model, Interface và Middleware  thực hiện xử lý request và trả về response Tạ gó Model: Class Article có quan hệ hợp thành từ các class Comment, Vocabulary, Like và User. Mỗ bà viết được tạo bởi một user và mổ và vết chứa các thông tin về comment, vocabulary và like,.. Ngoài ra, class Translate định nghĩa các thuộc tính lên quan tới bà dịch, là một class kế thừa của class Article.
