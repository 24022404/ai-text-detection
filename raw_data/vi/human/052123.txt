CSS (Cascading Style Sheets) CSS là từ viết tắt của Cascading Style Sheets: công dụng dùng để trang trí trang web và thường đi ư ợc gắn với các ngôn ngữ như HTML, PHP dùng làm nổ bật Mỗ câu lệnh CSS s ẽ điịnh dạng m ột phần nhất định của HTML, ví dụ như: font của chữ, đường viền, màu nền, căn chỉnh hình ảnh,… JAVASCRIPT − JavaScript là một ngôn ngữ lập trình kịch bản dựa trên đối tượng đi lược phát triển từ các ý niệm nguyên mẫu được tạo ra vào năm 1995 b ở Brendan Ech tạ Netscape. Mục đích bạn đi cầu để nâng cao khả năng tương tác của trang web với người sử dụng.
