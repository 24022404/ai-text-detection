Ngoài ra, ứng dụng có thể cài đặt chạy thử nghiệm trên localhost. Để chạy thử nghiệm ứng dụng trên localhost cần thực hiện tuần tự các bước sau () cài đặt môi trường, cấu hình ứng dụng như: NodeJS, Gt, MySQL Workbench () clone mã nguồn ứng dụng, () cài đặt các thư viện cần thiết, (v) cấu hình file mô trường cho server kết nối với CSDL, (v) chạy khởi tạo Database MySQL và (v) chạy ứng dụng.
