Ở bảng assets cũng có trường form là một mảng điể lưu gá trị của các trường tuỳ chỉnh tương ứng. Các phần tử là một JSON gồm d,note,name ,type, value STT Tên Kểu dữ lệu Nullable Mô tả 1 d string No d của trường tùy chỉnh 2 name string No Tên của trường tùy chỉnh 3 note strng Yes Mô tả của người tạo vớ trường tùy chỉnh 4 type string NO Kểu dữ lệu của trường tùy chỉnh 5 value string Yes Gá trị của trường tùy chỉnh Bảng 5.1: Ch tết về từng gá trị trong trường formVớ gả pháp trên, chúng ta chỉ cần thêm một mảng các object vào trường form thì sẽ có điược danh sách các trường tùy chỉnh điố vớ thư vện hoặc điề xuất tương ứng.
