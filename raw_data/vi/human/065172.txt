MySQL bao gồm 2 thành phần chính: MySQL Server và MySQL client. MySQL Server là một hệ máy tính cà điặt phần mềm MySQL dành cho server điể chúng ta có thể lưu trữ dữ lệu trên đió, dữ lệu điược cà điặt trong các bảng và các bảng điược lên kết với nhau. MySQL client là các phần mềm có thể thực hiện điược truy vấn lên một MySQL server và nhận kết quả trả về. Có rất nhều các công cụ mễn phí có thể sử dụng điể làm MySQL client bao gồm: MySQL Workbench, v.v.
