Collecting data: To collect cryptocurrency data on a daily basis, I utilized the Pycoingecko library, which is specifically designed to provide a Python API for easy access to CoinGecko data. Pycoingecko simplifies the process of fetching cryptocurrency-related information from CoinGecko’s extensive database through Python. In comparison to other available options like yfinance and Binance API, I chose to use the Pycoingecko library for several reasons.
