The MVC design pattern is suitable for this project for several reasons. Firstly, it provides a clear separation of concerns, which makes it easier to maintain and extend the code. Secondly, it helps to improve the overall performance of the application by reducing the amount of code that needs to be executed at any given time. Thirdly, it allows for greater modularity, as changes to one component of the application can be made without affecting the others. Finally, it makes it easier for multiple developers to work on the same project, as each component can be developed and tested independently before being integrated into the final product.
