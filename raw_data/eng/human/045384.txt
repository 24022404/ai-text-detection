Delegate call Injection : a security issue that arises when a contract uses delegate calls in an insecure manner, allowing an attacker to exploit the contract’sbehavior and potentially manipulate its state or execute malicious code. This vulnerability occurs when a contract blindly trusts and delegates control to another contract without properly validating or sanitizing the input. If the called contract contains malicious code or unintended logic, it can manipulate the state of the called contract and potentially cause financial loss or other security breaches. To mitigate this vulnerability, developers should carefully review and audit the code, validate inputs, and implement proper access control and security checks to prevent unauthorized or malicious delegate calls.
