After the warehouse staff performs an inventory with RFID, the system receivesa data set that includes all the RFID codes in the warehouse and the actual stor age location of each RFID code at the warehouse. Next, the system compares each RFID code and their storage location according to the data on the system and thedata obtained from the inventory. The result of this comparison is the final inven tory result.
