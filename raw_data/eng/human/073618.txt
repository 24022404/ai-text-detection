When the JWT string is received from the server, the client stores this informa tion in the browser. From here, every time the user wants to make a request to the server, the JWT is invoked and attached to the header of the sending request. The JWT will be decrypted with a secret string only available on the server side, then the decrypted string will be used to authenticate the account, check the account’s authorization, and check the expiration date. If all the information in the JWT is valid, the server will process the client’s request and return the result. Otherwise, API access to the server will be blocked.
