When using Redux, the whole global state of the app is stored in an object tree inside a single store. The only way to change the state tree is to create an action, an object describing what happened, and dispatch it to the store. To specify how the state gets updated in response to an action, I need to write pure reducer functions that calculate a new state based on the old state and the action. The Redux model is different from the traditional MVC model, the MVC model is divided into 3 separate parts when building: data, interface and logic processing. The data flow of this model is a bidirectional data flow, when changing data in one component can affect the state of the application in other components.
