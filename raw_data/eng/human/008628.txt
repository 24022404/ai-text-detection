Use case approve/reject the request Admin can approve or reject the request of the supplier. After approval, the system will send an email with account information to a supplier so that the supplier can log in to the system or if the reject system will send an email with a reason and link to update the request. Admin also has other actions with the supplier, such as blocking, editing information, and changing the password, but these use cases are not in this module. Admin can approve/reject the distributor request similar to the supplier’s request.
