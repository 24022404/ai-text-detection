Auth Controller function signupThis function handles the request when user signups. It checks for all the re quired fields, if there is empty required field then it will return error to the client. It then checks for the uniqueness of username and email. The password length must be longer than 6 characters. It then hashes the password, It createsa new User document in the database. After that, it creates new access token and refresh token for the client. The refresh token is stored in the client cookie and will expired after 30 days. The access token is stored in the client local storage and will be expired after 1 day. The access token is required to be sentwith every request from the application. If the access token is expired, the re fresh token will be used to generate new access token. If the refresh token is expired, user must login again.
