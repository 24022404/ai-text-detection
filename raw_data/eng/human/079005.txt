Multilayer Perceptron Experiments I have experimented with different perceptron-based neural networks. The model uses square image as input and there are four hidden layers, each layer using the rectified ar unit (relu) activation function. The output of the final hidden layeris fed into a fully connected output layer. This output layer is responsible for clas sifying the sample. Due to 20 malware classes in the dataset, the output vector has 20 dimensions.
