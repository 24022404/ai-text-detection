The Database package is a concise package that serves to represent the MySQL database, and its sole responsibility is to provide storage functionality. Therefore, a detailed description of its design is not necessary.Figure 4.6: AR package details The last package is the AR package, responsible for receiving the path data from the server and presenting it in an Augmented Reality environment. The main class of this package is the ARImageAndNavigation class, which connects to the API and retrieves the JSON path data by calling the getPath() method. The JSON path data is then passed to the calibration() method to be converted into real-world anchors, and the planeDetection() method is called to detect the plane in the camera view. Once the plane is detected, the setRenderable() method is used to place the 3D arrow anchors on the plane.
