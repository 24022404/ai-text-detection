In this model, the Server assumes the role of connecting to the database, handling the logic, providing APIs that allow clients or 3rd parties to access and use those APIs to access and exploit data. When a client or a 3rd party sends a request to the Server, the Server authenticates the information the user is sent to. After the authentication is complete, ensuring valid access rights, the server processes the request, updates the data into the database if necessary, and returns the data to the requesting party. The client assumes the role of displaying the interface on the Web interface so that the user can easily interact and make requests to send to the Serverside. Server is built according to the MVC architecture model, including 3 com ponents Mode, View, Controller. The client is built on top of Redux’s architecture and is repackaged into modules corresponding to separate functions.
