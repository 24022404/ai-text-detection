Consensus Layer : This layer ensures a consistent state of the blockchain. At the time of data recording, Ethereum will take about 12 - 14 seconds to create a block, which means that many miners can create a valid block at the same time, resulting in Stale blocks (a stale block is a valid block, however, this block must not be on the longest chain of the blockchain). Ethereum uses many consensus algorithms to choose the branch with the highest cumulative difficulty. Previously, consensus algorithms using PoW took a lot of energy and time, so Ethereum is planning to replace PoW with PoS.
