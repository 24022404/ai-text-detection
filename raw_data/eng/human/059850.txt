Alternate event streamNoneA.3 Use Case Register A.3.1 Class diagram In this use case, the User actor initiates the registration process by clicking the Register" button. The user fills out a registration form that is displayed by the system. The system verifies the user’s details once they submit the form, at which point a new user account is created. The system will urge the user to update their information and resubmit the form if there are mistakes in the information they have provided. When a user registers, the system logs them in and directs them to the main application.
