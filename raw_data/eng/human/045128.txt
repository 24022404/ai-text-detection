Redux  is a predictable state container designed to help write JavaScript apps that behave consistently across client, server, and native environments and are easy to test. While it’s mostly used as a state management tool with React, developer can use it with any other JavaScript framework or library. It’s lightweight at 2KB(including dependencies), so developer donnot have to worry about it making ap plication’s asset size bigger.
