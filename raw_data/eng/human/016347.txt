Docker Images: To create a Docker container, you need a Docker image. An image is a lightweight, standalone, and executable software package that includes everything needed to run an application - code, runtime, libraries, dependencies, and system tools. Images are built using a Dockerfile, which contains instructionsfor assembling the image . Docker Registry: Docker images are stored in a registry, like Docker Hub or a private registry. Docker Hub is a cloud-based registry where you can find and share public Docker images. Private registries allow organizations to store their custom images securely.
