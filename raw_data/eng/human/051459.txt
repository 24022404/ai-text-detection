Netcode framework Unity, since version 5.2, has been offering a first-party netcode solution calledUNet9. UNet is composed of 2 parts: HLAPI (high-level API) and LLAPI (low level API). HLAPI lets developer build game with ready-to-use components and provides access to Unity engine and editor integration. On the other hand, LLAPI is a real-time transport layer that is built upon optimized UDP based protocol.
