GameObject: Unity defines GameObjec as an object that represents the Assets in the game such as characters, plants, tools, props, cameras, effects... GameObject all contain a basic property called Transform, used to set GameObject’s position,orientation and size.Components: Components are properties added to GameObject such as Anima tion, sound, 3D models, effects, ... to build, combine different elements to define morphologies, behaviors,... of the desired object in the game.
