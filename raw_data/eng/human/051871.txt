Spring Boot Framework Spring Boot is a framework that is written in Java - the programming languagethat was taught in many courses during the time I studied in HUST. Despite in heriting most weaknesses of Java (boilerplate code, large memory consumption...),I have to give credits to Spring Boot for being one of the most powerful frame works to develop an API server. It supports a multitude of features, even more than I could ask for, from natively support JPA queries, caching capabilities and evensecurity functions. Also, the strict convention of Java helps developing and main taining processes a lot as the code can be self-explained and intuitive (most of the time) without significant efforts to document them.
