Software architecture selection Game development is different from traditional software engineering in thatthere are no real functional requirements and the customers buy and use the software only because it is engaging and fun. One of software engineering challenges in game development has been identified as Diverse Assets - game de velopment is not simply a process of producing source code, but involves assets such as 3D modes, textures, animations, sound, music, dialog and video. In Funny Zoo, software elements are grouped into 3 major components in which common software architectures are applied.
