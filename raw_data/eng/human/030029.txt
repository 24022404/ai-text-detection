In detail, inside this recurrent structure, each input is transformed into an output with the help of one cell h. For instance, we know from regular neural networks that the word ikwould become Iif we translated it from Dutch to English. It also connects back to itself, so a better prediction will be made when new input arrives by using the context from previous forward passes.
