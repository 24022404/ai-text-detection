General requirements The input boxes on the interface need to ensure the following principles: (i) The input data needs to be checked by the system for binding conditions, and an error will be displayed if these requirements are not met ( ii) For the selection of optional data, a search function must be provided to facilitate finding data in the case of large data (iii) For the data type of day, month and year, it is necessary to provide select interface, not for manual data entry.
