User interface architecture For user interfaces, MVP pattern is used to structure all screens and popups in our game. Model–view–presenter (MVP) is a derivation of the model–view–controller (MVC) architectural pattern. The model is an abstraction defining the data to be displayed. The view is a passive interface that displays data (the model) and routesinvocations (from user) directly to the presenter. The job of the presenter is to re trieve data from repositories (the model) and format it for display in the view.
