Graph Construction The Graph Construction task involved the use of Mapbox to create a map based on the floor plan of Aeon Mall. The map was stored in a JSON file with objects such as polygons as stores, rooms, and points. Each of these objects had its own set of coordinates that defined its location on the map.Figure 5.1: AEON Mall 1st Floor PlanThe use of Mapbox allowed for the creation of an accurate and detailed repre sentation of the indoor space, making it easier for users to navigate within the mall.
