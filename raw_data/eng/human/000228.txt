Talking about reliability , the internal modules (Machine Learning Inference Models, Data Collecting System and Scheduled Standardizer) have shown that they can be trusted, especially after Message Queue component was integrated. I could not recall a system outage caused by those components in the last three to four months. Also, despite their reliability (until now), I still apply the motto "Trust but verify", which means that those components are still closely monitored. However,for external modules - UI Web application and API servers - both Statistical server and Users’ server, there has not been enough workload to push them to limit so that I can observe how would they behave with real users.
