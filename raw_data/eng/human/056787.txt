The attention mechanism can be described as follows. Given a list of items, each represented by a key (K) and a value (V), a query (Q) aims to identify the important items in the list. To achieve this, the query computes similarity scores between itself and each key (K). The method for computing these similarity scores is flexible and not restricted to a specific approach. A commonly used choice is the dot product or a bi-ar function. The similarity scores are then normalized to form a probability vector known as attention scores. Each value in the attention scores represents the importance of the corresponding item.
