Salient object detection aims to identify the most visually distinctive objects in an image. This paper introduces SAC-Net, a novel deep learning architecture leveraging Spatial Attenuation Context to enhance salient object detection performance. Our approach incorporates a spatial attention mechanism that adaptively learns to attenuate irrelevant background regions while emphasizing salient objects. Specifically, SAC-Net integrates a context-aware module that captures both local and global spatial relationships, enabling the network to better distinguish salient regions from complex backgrounds. We employ a two-branch network structure, with one branch focusing on feature extraction and the other on spatial context modeling. The outputs of these branches are fused using the learned spatial attention maps. Extensive experiments on several benchmark datasets demonstrate that SAC-Net achieves state-of-the-art performance, outperforming existing methods in terms of precision, recall, and F-measure. The proposed model exhibits robustness to cluttered scenes and complex object shapes, offering significant improvements in salient object detection. Keywords: Salient Object Detection, Spatial Attention, Deep Learning, Context Modeling, Computer Vision.
