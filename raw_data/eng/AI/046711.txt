This paper addresses the challenge of image colorization with limited training data, a significant hurdle for deep learning-based approaches. We introduce a novel few-shot colorization framework leveraging memory-augmented networks. Our approach employs an external memory module to store and retrieve relevant color priors from a small set of reference images, effectively compensating for data scarcity. The memory module facilitates the transfer of color information by dynamically adapting to the input grayscale image. This allows the network to generate plausible colorizations even with only a few training examples. Experimental results on benchmark datasets demonstrate that our method outperforms existing few-shot colorization techniques, achieving superior color accuracy and visual quality. Key advantages include improved generalization ability and reduced reliance on large-scale datasets. Our contributions pave the way for more practical and efficient colorization solutions, particularly in domains where acquiring extensive labeled data is challenging. Keywords: Few-Shot Learning, Image Colorization, Memory Networks, Deep Learning, Color Transfer, Image Processing.
