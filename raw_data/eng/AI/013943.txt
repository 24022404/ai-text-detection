Object detection and instance segmentation models often exhibit poor calibration, particularly when trained on long-tailed datasets where some classes have significantly fewer training examples than others. This work investigates the calibration problem in the context of long-tailed object detection and instance segmentation, focusing on the discrepancy between predicted confidence scores and actual accuracy. We propose a novel calibration method, TailCalib, which adapts temperature scaling based on per-class statistics and incorporates a learnable recalibration module to adjust confidence scores specifically for tail classes. Experimental results on the LVIS dataset demonstrate that TailCalib significantly improves calibration metrics, such as Expected Calibration Error (ECE) and Maximum Calibration Error (MCE), without sacrificing detection or segmentation performance. TailCalib outperforms existing calibration techniques, leading to more reliable confidence estimates and improved decision-making in downstream applications. Our analysis provides insights into the factors contributing to miscalibration in long-tailed object detection and instance segmentation, offering a practical solution for enhancing model trustworthiness. Keywords: Object Detection, Instance Segmentation, Calibration, Long-Tailed Learning, Deep Learning.
