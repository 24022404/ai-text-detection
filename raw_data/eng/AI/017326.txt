This paper proposes NENET, a novel edge learnable network designed for link prediction in scene text. The objective is to improve the accuracy of linking text elements in images, enabling better scene text understanding. NENET employs a graph-based approach, leveraging a unique combination of visual and linguistic features to learn edge representations. The network is trained using a contrastive loss function, allowing it to effectively capture complex relationships between text elements. Experimental results demonstrate that NENET outperforms state-of-the-art methods, achieving significant improvements in link prediction accuracy. The key contributions of this research include the introduction of a learnable edge module and a novel loss function, which enable the network to adapt to diverse scene text scenarios. NENET has potential applications in various areas, including image understanding, natural language processing, and computer vision. Key keywords: link prediction, scene text, edge learnable network, graph-based approach, computer vision, natural language processing.
