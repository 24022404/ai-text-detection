**Abstract:**  
Efficient processing of 3D point cloud data is critical for various applications such as autonomous driving, robotics, and virtual reality. However, the high density and large size of raw point clouds pose significant computational and storage challenges. This paper introduces MOPS-Net, a novel Matrix Optimization-driven Point cloud Sampling Network designed for task-oriented 3D point cloud downsampling. Unlike traditional random or heuristic-based sampling methods, MOPS-Net leverages a matrix optimization framework within a deep neural network to adaptively select critical points that best preserve downstream task performance, such as classification or segmentation. The proposed architecture integrates an optimization module that explicitly models point selection as a learnable process, ensuring the sampled subset retains geometric structures and semantic information. Extensive experiments on benchmark datasets demonstrate that MOPS-Net achieves superior accuracy and efficiency compared to existing state-of-the-art downsampling techniques, enabling faster processing and reduced memory usage without significant loss in task performance. The network also exhibits strong generalization across different tasks and varying sampling ratios. Our results highlight the potential of optimization-driven neural networks for efficient 3D data processing and provide a robust foundation for further research in intelligent point cloud simplification.  
**Keywords:** 3D point cloud, downsampling, matrix optimization, deep learning, task-oriented processing, neural network, data compression, segmentation, classification.
