This paper introduces Supervised Topological Maps (STM), a novel approach for learning topological representations of data under explicit supervision. Unlike traditional methods that rely on unsupervised learning to extract topological features, STM leverages labeled data to guide the construction of maps that are both topologically accurate and semantically meaningful. The proposed method involves a modified self-organizing map architecture integrated with a supervised loss function that penalizes misclassifications based on the learned topological structure. Experiments on benchmark datasets demonstrate that STM achieves superior classification accuracy compared to unsupervised topological mapping techniques and other supervised learning algorithms, particularly in scenarios with high-dimensional data and complex decision boundaries. Furthermore, the learned topological maps provide valuable insights into the underlying data structure and the relationships between different classes. The key contributions of this work include the introduction of a supervised learning framework for topological map generation, improved classification performance, and enhanced interpretability of the learned representations. Keywords: Topological Maps, Supervised Learning, Self-Organizing Maps, Classification, Dimensionality Reduction, Data Visualization.
