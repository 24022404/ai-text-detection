Autonomous driving systems rely heavily on accurate 3D object detection for safe navigation and decision-making. This paper introduces a novel multi-view 3D object detection network designed to improve the accuracy and robustness of object detection in complex urban environments. Our approach integrates information from multiple camera perspectives using a frustum-based feature fusion module that effectively aggregates context from different viewpoints. This module reduces ambiguity and enhances feature representation for each object proposal. Furthermore, we employ a spatial attention mechanism to selectively focus on informative regions within each frustum, mitigating the impact of irrelevant background noise. Experimental results on the challenging KITTI dataset demonstrate that our proposed network significantly outperforms existing state-of-the-art methods, achieving improvements in both detection accuracy and recall. The enhanced performance validates the effectiveness of our multi-view fusion and spatial attention strategies, offering a promising solution for robust 3D object detection in autonomous driving applications. Keywords: Autonomous Driving, 3D Object Detection, Multi-View Fusion, Deep Learning, Spatial Attention.
