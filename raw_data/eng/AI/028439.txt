Abstract:

Automated event detection in large-scale data streams is a critical challenge across diverse Information Technology applications, including security monitoring, log analysis, and multimedia indexing. This paper presents a novel unsupervised method for automated event detection that leverages an iterative clustering-based segmentation approach. The objective of this study is to accurately identify and segment events from unlabeled temporal data without the need for manual annotations or predefined event templates. The proposed methodology employs iterative clustering techniques to dynamically partition data streams into candidate event segments, extracting meaningful features and refining cluster boundaries over successive iterations. Experimental evaluations were conducted on multiple real-world datasets, demonstrating that the approach consistently outperforms traditional segmentation and clustering baselines in terms of detection accuracy, computational efficiency, and adaptability to varying event temporal structures. The results indicate robust performance in scenarios with unknown event patterns and minimal prior information, highlighting the system’s potential for deployment in real-time monitoring environments. This research contributes a scalable, parameter-light solution for unsupervised event detection, expanding the capabilities of data-driven event monitoring systems and reducing reliance on annotated training data. Key keywords include unsupervised learning, event detection, iterative clustering, segmentation, temporal data analysis, and automated monitoring systems.
