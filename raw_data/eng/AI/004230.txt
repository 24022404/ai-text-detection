The design of the system revolves around several cohesive packages, each responsible for specific core functionalities, and all closely integrated through a robust authentication mechanism. The "Admin" package assumes the fundamental role of managing all users and tickets across the platform, ensuring high-level oversight and control. Meanwhile, the "Project" package is tailored to facilitate both customers and agents in creating and accessing pertinent ticket information, acting as an interface for collaborative ticket generation and management. Importantly, these packages—Admin, Agent, and Customer—are critically dependent on a centralized "Authentication" package, which governs user authentication and security processes. Each package’s models are structured to inherit from the Model User, promoting consistency and efficient user management. The "Project" model, along with other related packages, supports the potential for multiple associated tickets, underscoring the system's capability for comprehensive ticket management.
