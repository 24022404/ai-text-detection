Distributed computing has become a cornerstone for handling large-scale data, yet communication overhead remains a critical bottleneck. This paper addresses the challenge of efficiently computing Singular Value Decomposition (SVD) in distributed environments, a fundamental operation in data analysis and machine learning. We propose a novel communication-efficient distributed SVD algorithm based on local power iterations. Our approach minimizes inter-node communication by performing multiple power iterations locally on each node before exchanging partial results, significantly reducing the communication rounds required for convergence. Theoretical analysis demonstrates that the proposed method achieves near-optimal communication complexity while maintaining high accuracy. Experimental results on large-scale datasets show that our algorithm outperforms existing distributed SVD methods in terms of both communication cost and computational efficiency. The proposed method is particularly advantageous for applications in distributed machine learning, where SVD is frequently used for dimensionality reduction and feature extraction. This work contributes a scalable and practical solution for distributed SVD, enabling efficient large-scale data processing with minimal communication overhead.  

**Keywords**: Distributed computing, Singular Value Decomposition (SVD), communication efficiency, power iterations, large-scale data processing.
