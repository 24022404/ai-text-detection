This paper addresses the challenge of efficient deep neural network (DNN) execution on mobile devices, where computational resources and memory are limited. The objective is to develop a novel weight pruning method, termed PCONV, which introduces desirable sparsity in DNNs to facilitate real-time execution. PCONV employs a hybrid approach, combining structural and unstructured pruning techniques to effectively reduce model complexity while preserving accuracy. Experimental results demonstrate that PCONV outperforms state-of-the-art pruning methods, achieving significant reductions in model size and computational overhead. On mobile devices, PCONV-enabled DNNs exhibit substantial speedups, making them suitable for real-time applications such as image classification, object detection, and speech recognition. The key contributions of this research include the introduction of a novel pruning paradigm, significant improvements in model efficiency, and the enablement of real-time DNN execution on resource-constrained mobile devices. Keywords: DNN weight pruning, sparsity, real-time execution, mobile devices, deep learning, model compression.
