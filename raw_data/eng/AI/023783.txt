3D object detection is critical for autonomous systems, but acquiring labeled 3D data is expensive. This paper introduces a novel transferable semi-supervised learning framework for 3D object detection using RGB-D data, leveraging knowledge from labeled source domains to improve performance in unlabeled target domains. Our approach employs a feature alignment module that minimizes domain discrepancy by learning domain-invariant feature representations. We further introduce a self-training strategy with dynamic pseudo-label refinement, mitigating the noise inherent in pseudo-labels generated from unlabeled data. Experiments on benchmark datasets demonstrate that our method significantly outperforms existing semi-supervised and domain adaptation techniques, achieving state-of-the-art results in cross-domain 3D object detection. The proposed framework enables effective transfer of knowledge across different RGB-D datasets, reducing the reliance on extensive manual annotation and improving the practicality of 3D perception systems. Keywords: 3D object detection, semi-supervised learning, domain adaptation, RGB-D data, transfer learning, self-training.
