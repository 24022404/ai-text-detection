This paper presents PFDet, a state-of-the-art object detection system that achieved 2nd place in the Open Images Challenge 2018 Object Detection Track. The objective of this research is to develop an accurate and efficient object detection model capable of handling a large number of classes and instances. To achieve this, we employ a novel approach combining feature pyramid networks with a modified Faster R-CNN architecture. Our method utilizes a multi-scale feature extraction technique, enabling the detection of objects at various scales. The results show that PFDet outperforms several baseline models, achieving a significant improvement in detection accuracy. Key findings include a 5% increase in mean average precision compared to the top-performing single-model entry. The contributions of this research lie in the design of a robust and scalable object detection framework, with potential applications in autonomous vehicles, surveillance, and image analysis. The PFDet system demonstrates the effectiveness of combining advanced feature extraction techniques with well-established object detection architectures, making it a valuable contribution to the field of computer vision and object detection. Keywords: object detection, Open Images Challenge, feature pyramid networks, Faster R-CNN, computer vision.
