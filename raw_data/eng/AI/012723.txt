Bipartite network embedding aims to learn low-dimensional representations of nodes in bipartite graphs, which is crucial for various applications like recommendation and link prediction. However, existing methods often struggle to capture high-order relationships and complex node interactions inherent in multiplex bipartite networks. This paper introduces a novel approach for multiplex bipartite network embedding using Dual Hypergraph Convolutional Networks (DHCN). We construct dual hypergraphs from the original multiplex bipartite graph to explicitly model high-order relationships among nodes of the same type and across different types. Then, we propose a DHCN model to learn node embeddings by aggregating information from both hypergraphs, capturing both intra-type and inter-type interactions. The DHCN model employs hypergraph convolutional layers to propagate and aggregate node features within each hypergraph, and incorporates a cross-hypergraph aggregation mechanism to fuse information from the dual hypergraphs. Experiments on several real-world datasets demonstrate that our DHCN model consistently outperforms state-of-the-art bipartite network embedding methods in link prediction and node classification tasks. The results highlight the effectiveness of modeling high-order relationships via hypergraphs and leveraging dual hypergraph structures for improved multiplex bipartite network embedding. Keywords: Bipartite Network Embedding, Hypergraph Convolutional Networks, Multiplex Networks, Representation Learning, Link Prediction.
