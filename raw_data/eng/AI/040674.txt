Objective: Live video streaming platforms generate massive, rapidly evolving interaction graphs reflecting user behaviors and network conditions. Accurately modeling these dynamic structures is critical for tasks such as quality-of-experience prediction, anomaly detection, and resource allocation. This paper introduces EGAD, a novel framework that combines evolving graph representation learning with self-attention mechanisms and knowledge distillation to capture temporal patterns in live streaming events.

Methods/Approach: EGAD leverages a temporal self-attention module to weigh historical interactions and emphasize salient changes in the streaming graph over time. A graph neural network backbone encodes node and edge features into low-dimensional embeddings, which are updated incrementally to reflect new events. To ensure scalability on large-scale streaming datasets, we incorporate a teacher–student knowledge distillation strategy: a high-capacity “teacher” model trains a compact “student” network, preserving performance while reducing inference time and memory footprint. The framework supports both transductive and inductive settings, enabling real-time adaptation to unseen users or sessions.

Results/Findings: Experiments on two real-world live streaming datasets demonstrate that EGAD outperforms state-of-the-art dynamic graph models by 4–7% in AUC for interaction prediction and reduces inference latency by up to 60%. Ablation studies confirm the complementary benefits of self-attention for temporal sensitivity and distillation for efficiency.

Conclusion/Implications: EGAD offers an effective and scalable solution for dynamic graph analysis in live video streaming, improving predictive accuracy and operational efficiency. Its modular design facilitates integration into existing streaming platforms, enabling enhanced user experience, proactive resource management, and robust anomaly detection.

Keywords: evolving graph representation learning, self-attention, knowledge distillation, live video streaming, dynamic networks.
