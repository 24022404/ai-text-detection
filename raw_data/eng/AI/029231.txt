**Abstract:**

This paper introduces Res2Net, a novel backbone architecture designed to enhance multi-scale feature representation in convolutional neural networks (CNNs) for computer vision tasks. The primary objective is to address the limitations of existing backbone models, such as ResNet, in capturing fine-grained features across varying scales, which are vital for tasks like object detection, semantic segmentation, and image classification. The proposed Res2Net architecture incorporates a modular approach that splits a single residual block into multiple hierarchical scales, enabling simultaneous extraction of diverse receptive fields within each block. This inherently strengthens the multi-scale capability while maintaining computational efficiency. Extensive experiments conducted on benchmark datasets demonstrate that Res2Net consistently outperforms traditional backbones with minimal overhead, achieving superior accuracy in tasks including ImageNet classification and COCO object detection. The findings highlight the effectiveness and versatility of the Res2Net module, which can be seamlessly integrated with various existing frameworks. In conclusion, Res2Net represents a significant advancement in CNN backbone design, providing a more powerful and flexible approach for multi-scale feature learning in modern computer vision systems.

**Keywords:** multi-scale feature, backbone architecture, Res2Net, convolutional neural networks, image classification, object detection, semantic segmentation.
