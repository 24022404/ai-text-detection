This paper introduces TRACE, a novel framework for image search with text feedback that leverages transformers to effectively integrate visual and linguistic representations. The system addresses the challenge of refining image search results based on iterative user feedback expressed in natural language. TRACE employs a three-stage approach: Transformation, Aggregation, and Composition. First, visual features extracted from a pre-trained convolutional neural network and textual features from a transformer model are transformed into a shared embedding space. Second, these multi-modal representations are aggregated using a cross-attention mechanism to capture relevant relationships. Finally, a novel compositional module refines the search query based on user feedback, generating updated image embeddings that reflect the desired modifications. Experimental results on benchmark datasets demonstrate that TRACE significantly outperforms existing methods, achieving state-of-the-art performance in interactive image retrieval. The proposed framework demonstrates the effectiveness of transformer-based models in integrating visual and linguistic information for improved search accuracy and user experience.
Keywords: Image search, text feedback, transformers, visiolinguistic representation, cross-modal attention, interactive retrieval.
