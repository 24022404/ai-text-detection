This paper presents the development of a compressed object detection model based on YOLOv4, specifically tailored for efficient deployment on embedded GPU platforms within autonomous systems. The primary objective is to address the challenges of limited computational resources and power constraints commonly encountered in embedded environments, such as those found in robotics and autonomous vehicles. We propose a novel compression approach combining model pruning and quantization techniques to significantly reduce the model size and computational complexity while preserving detection accuracy. The proposed framework was implemented and evaluated on an NVIDIA Jetson platform, demonstrating substantial reductions in memory usage and inference latency compared to the baseline YOLOv4 model. Experimental results show that our compressed model maintains over 95% of the original detection accuracy while achieving up to 60% reduction in model size and a 2x increase in inference speed. This work underscores the feasibility of deploying advanced deep learning-based object detection on resource-constrained autonomous platforms, enabling real-time perception capabilities. Key contributions include the integration of compression strategies with the YOLOv4 architecture and comprehensive performance evaluation on actual embedded GPU hardware. Our findings have significant implications for the scalable and energy-efficient deployment of AI-driven perception systems in a broad range of autonomous and edge computing applications.

Keywords: YOLOv4, object detection, model compression, pruning, quantization, embedded GPU, autonomous system, real-time inference.
