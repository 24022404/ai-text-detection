Unsupervised domain adaptation (UDA) addresses the challenge of transferring knowledge from a labeled synthetic domain to an unlabeled real-world domain, particularly beneficial for object detection tasks where real-world annotation is expensive. This paper proposes a novel UDA framework to improve anchorless object detection by mitigating domain discrepancies between synthetic and real images. Our approach leverages a multi-level feature alignment strategy, incorporating both adversarial learning at the feature level and a self-training mechanism to generate pseudo-labels on the target domain. Specifically, we introduce a feature discriminator to minimize domain divergence across different feature layers, enabling better feature alignment. Furthermore, we refine the pseudo-labels generated by the detector on real images using a confidence-aware filtering method, leading to more robust self-training. Experiments on benchmark datasets demonstrate that our method significantly improves object detection accuracy in the target domain compared to existing UDA techniques for object detection, achieving state-of-the-art performance. This work offers a practical solution for deploying object detectors trained on synthetic data to real-world scenarios without requiring manual annotation.
Keywords: Unsupervised Domain Adaptation, Object Detection, Anchorless Detection, Synthetic to Real, Adversarial Learning, Self-Training.
