Correlation clustering aims to partition a set of objects into clusters based on pairwise similarity information, optimizing an objective function that balances agreements and disagreements. This paper addresses the computational challenges associated with applying correlation clustering to large-scale datasets. We introduce a novel, scalable optimization algorithm based on a combination of message passing and local search techniques. Our method efficiently explores the solution space, achieving significant improvements in runtime compared to existing state-of-the-art algorithms while maintaining competitive solution quality. Experimental results on several benchmark datasets, including those with millions of data points, demonstrate the effectiveness of our approach. The proposed algorithm provides a practical solution for large-scale correlation clustering problems, enabling applications in diverse fields such as social network analysis, document clustering, and bioinformatics. Key words: Correlation Clustering, Large-Scale Optimization, Message Passing, Clustering Algorithms, Data Mining.
