Semi-supervised classification aims to leverage unlabeled data to improve classification performance when labeled data is scarce. This paper introduces a novel Masked Label Prediction (MLP) framework built upon a unified message passing model for semi-supervised node classification. The proposed model iteratively refines node embeddings by aggregating information from both labeled and unlabeled nodes, while MLP strategically masks node labels during training, forcing the model to predict these masked labels and learn robust representations. This approach encourages the model to effectively utilize information from unlabeled data, leading to improved generalization. Experiments on several benchmark datasets demonstrate that the proposed MLP model achieves significant performance gains compared to existing semi-supervised classification methods. The results highlight the effectiveness of the unified message passing architecture and the benefits of the masked label prediction strategy for learning with limited labeled data. Key words: Semi-Supervised Learning, Node Classification, Message Passing, Graph Neural Networks, Masked Label Prediction.
