Zero-shot learning (ZSL) aims to recognize unseen classes by transferring knowledge from seen classes through semantic descriptions. This paper addresses the challenge of effectively leveraging class descriptions to improve ZSL performance. We propose a novel class description regularization (CDR) method that enforces consistency between predicted and provided class descriptions during training. Our approach utilizes a regularization term based on a similarity measure between predicted class embeddings generated by a deep neural network and the given textual descriptions, guiding the model to learn a more aligned feature space. Experimental results on benchmark datasets demonstrate that CDR significantly improves ZSL accuracy compared to existing methods. Specifically, our method achieves state-of-the-art performance on standard ZSL benchmarks and generalized ZSL settings. The findings indicate that explicitly regularizing the learned feature space with class descriptions enhances the transferability of knowledge to unseen classes. This work contributes a simple yet effective regularization technique that can be readily integrated into existing ZSL frameworks, advancing the state-of-the-art in zero-shot recognition. Keywords: Zero-shot learning, class descriptions, regularization, semantic embedding, knowledge transfer, machine learning.
