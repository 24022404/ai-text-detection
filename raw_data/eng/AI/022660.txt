Task-oriented 3D point cloud downsampling aims to reduce data redundancy while preserving features critical for downstream tasks. We introduce MOPS-Net, a novel learnable downsampling framework driven by matrix optimization principles. MOPS-Net formulates the downsampling problem as a matrix selection process, where a selection matrix is optimized to retain the most informative points based on task-specific criteria. The network architecture is designed to efficiently approximate this matrix optimization using differentiable operations, enabling end-to-end training. MOPS-Net dynamically adapts to the specific requirements of various downstream tasks, such as classification and segmentation, without requiring retraining for each new task. Experimental results on benchmark datasets demonstrate that MOPS-Net consistently outperforms existing downsampling methods, achieving superior performance on downstream tasks while significantly reducing computational costs. The proposed approach offers a principled and efficient solution for task-oriented point cloud processing, with potential applications in autonomous driving, robotics, and computer vision.

**Keywords:** 3D point cloud, downsampling, matrix optimization, deep learning, task-oriented learning.
