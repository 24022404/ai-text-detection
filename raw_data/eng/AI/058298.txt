Unsupervised Domain Adaptation (UDA) in object detection aims to bridge the performance gap between source and target domains without requiring labeled target data. However, existing methods often struggle with domain shifts and uncertainty in predictions, leading to suboptimal detection performance. This paper proposes an uncertainty-aware UDA framework for object detection that explicitly models prediction uncertainty to improve adaptation accuracy. Our approach integrates a probabilistic uncertainty estimation module into a state-of-the-art object detection architecture, enabling the model to identify and prioritize reliable predictions during adaptation. We employ adversarial training to align feature distributions across domains while leveraging uncertainty-guided pseudo-labeling to refine target domain predictions. Experiments on benchmark datasets demonstrate that our method outperforms existing UDA techniques, achieving significant improvements in mean average precision (mAP) under challenging domain shifts. The proposed framework not only enhances detection robustness but also provides interpretable uncertainty estimates, making it suitable for real-world applications such as autonomous driving and surveillance. This work contributes a novel perspective on uncertainty modeling in UDA, offering a practical solution for domain adaptation in object detection tasks.  

**Keywords**: Unsupervised Domain Adaptation, Object Detection, Uncertainty Estimation, Adversarial Training, Pseudo-Labeling, Domain Shift.
