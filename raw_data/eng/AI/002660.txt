This paper introduces a novel numerical demultiplexing technique for color image sensor measurements using non-linear random forest (RF) modeling. Conventional color filter arrays (CFAs) spatially sample red, green, and blue color components, requiring demosaicing algorithms for full-resolution color reconstruction. Instead of relying on spatial interpolation, our approach directly models the non-linear relationship between sensor measurements and underlying color values using RFs. By training RFs on a diverse set of color image patches, we learn a mapping function that effectively demultiplexes the raw sensor data. Experimental results demonstrate that our method achieves superior performance compared to traditional demosaicing algorithms and existing learning-based approaches, particularly in regions with high-frequency content and complex textures. The proposed technique significantly reduces color artifacts, improves image sharpness, and offers a robust solution for color image reconstruction. Key words: Color image demosaicing, Random Forest, Color Filter Array, Image reconstruction, Machine learning, Non-linear modeling, Image sensor.
