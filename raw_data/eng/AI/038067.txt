This paper proposes a novel weakly-supervised segmentation network designed for fast object detection, particularly focusing on small objects. The objective is to improve the accuracy and efficiency of object detection in images by leveraging multiple receptive fields and a small-object-focusing mechanism. Our approach utilizes a convolutional neural network (CNN) architecture that incorporates multiple receptive fields to capture objects of varying sizes, and a weakly-supervised learning strategy that requires only image-level annotations. The network is trained to optimize a loss function that balances the detection of small and large objects. Our results show that the proposed network achieves state-of-the-art performance on benchmark datasets, with significant improvements in detecting small objects. The key contributions of this work include the introduction of a multi-receptive-field architecture and a small-object-focusing mechanism, which enable fast and accurate object detection. The proposed network has potential applications in various computer vision tasks, such as autonomous driving, surveillance, and medical image analysis. Keywords: weakly-supervised segmentation, object detection, multiple receptive fields, small-object-focusing, convolutional neural networks (CNNs).
