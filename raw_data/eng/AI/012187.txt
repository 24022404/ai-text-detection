Neural signal classification is crucial for Brain-Computer Interfaces (BCIs) and biomedical applications. However, deploying complex classifiers like deep neural networks on resource-constrained devices poses a significant challenge. This paper introduces ResOT, a resource-efficient classification framework based on oblique decision trees. ResOT leverages a novel tree-learning algorithm that optimizes both classification accuracy and model size by adaptively selecting oblique splits based on a combination of data variance and feature importance. We evaluate ResOT on several benchmark neural signal datasets, demonstrating that it achieves comparable or superior classification accuracy to traditional decision trees and other shallow classifiers, while requiring significantly fewer parameters and computational resources than deep learning approaches. Results show an average reduction of 50% in model size compared to existing oblique tree methods with a similar level of accuracy. The ResOT framework provides a practical solution for real-time neural signal classification on embedded systems and mobile devices, enabling more accessible and energy-efficient BCI applications. Keywords: Neural Signal Classification, Oblique Decision Trees, Resource-Efficient Learning, Brain-Computer Interface, Embedded Systems.
