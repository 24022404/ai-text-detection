Generating images from scene graphs, which represent objects and their relationships, is a challenging task in computer vision. This paper introduces a novel approach, the Contextualized Object Layout Refinement Network (COLR-Net), to improve the visual quality and realism of generated images. COLR-Net addresses limitations in existing methods by incorporating contextual information during the object layout generation phase. Specifically, we employ a graph convolutional network to propagate contextual cues between objects, refining their positions and sizes based on semantic relationships within the scene graph. This refined layout is then used to guide image generation. We evaluate COLR-Net on the COCO-Stuff and Visual Genome datasets. Quantitative results demonstrate significant improvements in image quality metrics, including Inception Score and FID, compared to state-of-the-art scene graph to image generation models. Qualitative results further show that COLR-Net generates more coherent and realistic images with better object placement and inter-object relationships. The proposed method offers a substantial advancement in scene graph-based image generation by leveraging contextual information to improve object layout accuracy.
Keywords: Scene graph, image generation, graph convolutional network, contextual information, object layout refinement, computer vision.
