Network anomaly detection is critical for maintaining the security and stability of modern IT infrastructure. This paper introduces GEE, a novel Gradient-based Explainable Variational Autoencoder (VAE) designed to improve both the accuracy and interpretability of anomaly detection in network traffic data. GEE utilizes a VAE architecture to model normal network behavior and employs a gradient-based explainer to identify the input features most influential in anomaly scoring. The method involves training the VAE on normal network traffic, followed by computing gradients of the anomaly score with respect to the input features to highlight anomalous patterns. Experimental results on benchmark network intrusion datasets demonstrate that GEE achieves superior F1-score and detection accuracy compared to state-of-the-art anomaly detection techniques. Furthermore, the gradient-based explanation provides valuable insights into the underlying reasons for anomaly detection, enabling network administrators to understand and respond more effectively to security threats. GEE offers a promising approach for robust and explainable network anomaly detection, enhancing cybersecurity monitoring and incident response capabilities.
Keywords: Anomaly Detection, Variational Autoencoder, Explainable AI, Network Security, Gradient-based Explanation, Intrusion Detection.
