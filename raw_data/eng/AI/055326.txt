Users interact with the HelpDesk controller based on their roles: customers have the capability to view or close tickets, while admins handle ticket assignments, receiving new tickets from customers and delegating them to appropriate agents. As referenced in Figure 4.3, which presents the package diagram for ticket management, the detailed design features a user interface comprising a portal screen and a login page. The login process requires users to enter a valid username, password, and select their user type before accessing the system.
