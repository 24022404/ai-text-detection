This paper explores the application of deep reinforcement learning (DRL) to static neural compiler optimization. The objective is to improve code performance by optimizing compiler flags without requiring runtime feedback. We introduce a novel DRL framework that leverages a graph neural network to represent the compiler’s intermediate representation and an actor-critic network to select optimal optimization flag sequences. Our approach trains an agent to navigate the vast configuration space of compiler flags, learning effective strategies to enhance program execution speed. Experimental results on a diverse set of benchmark programs demonstrate that our DRL-based compiler significantly outperforms traditional optimization levels, achieving an average speedup of X% compared to O3 optimization. The findings suggest that DRL offers a promising avenue for automating and enhancing compiler optimization, leading to more efficient software execution. Key words: deep reinforcement learning, compiler optimization, neural networks, static analysis, code generation.
