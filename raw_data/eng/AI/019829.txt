This paper addresses the challenge of unsupervised feature learning by proposing a novel non-parametric instance-level discrimination approach. The objective is to learn high-quality, transferable visual representations from unlabeled data, circumventing the need for costly manual annotations. Our method treats each instance in the dataset as a distinct class and leverages a non-parametric softmax formulation to enforce discrimination at the instance level. By doing so, the model is encouraged to produce unique feature embeddings for each image, resulting in improved representation quality. We employ a memory bank to efficiently store and update feature representations, enabling scalable training on large datasets. Experimental results on benchmark image recognition tasks demonstrate that our unsupervised learning framework achieves competitive performance compared to established supervised and unsupervised methods, particularly in transfer learning and clustering scenarios. This approach is robust to changes in dataset size and provides a flexible solution for extracting discriminative features without relying on class labels. The findings highlight the potential of non-parametric instance-level discrimination in advancing unsupervised representation learning, facilitating broader applications in computer vision and related areas. Keywords: unsupervised learning, feature learning, instance discrimination, non-parametric, representation learning, computer vision.
