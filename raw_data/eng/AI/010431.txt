Colorization of grayscale images is a challenging task, especially when limited training data is available. This paper addresses the problem of few-shot colorization, where the goal is to generate realistic and visually appealing colorized images using only a small dataset of reference examples. We propose a novel memory-augmented network architecture that leverages external memory modules to store and retrieve color information from a sparse set of reference images. The memory module enables the model to generalize effectively across diverse scenes and objects, even with minimal training data. Our approach combines a deep convolutional neural network with an attention-based memory mechanism, allowing the system to adaptively select and apply relevant color patterns from the reference set. Experimental results demonstrate that the proposed method outperforms existing few-shot colorization techniques in terms of both perceptual quality and quantitative metrics. The model achieves superior performance in preserving fine details and producing natural color distributions, even under extreme data constraints. This work contributes to the field of image processing by introducing a memory-augmented framework that enhances the generalization capabilities of colorization models, making them more practical for real-world applications with limited data availability.  

**Keywords**: Few-shot learning, image colorization, memory-augmented networks, deep learning, attention mechanisms.
