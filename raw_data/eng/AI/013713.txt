Objective: Topological maps such as the Self-Organizing Map (SOM) are widely used for dimensionality reduction and data visualization, but their unsupervised nature limits discriminative performance when class labels are available. This paper introduces Supervised Topological Maps (STM), a novel framework that integrates class information directly into the map‐learning process to improve both visualization quality and classification accuracy.

Methods: STM augments the traditional neighborhood‐preserving SOM loss with a supervised term that encourages class‐consistent grouping on the map grid. During training, prototype nodes are updated via a hybrid cost function combining topological preservation and soft classification error. We derive efficient update rules and implement batch and stochastic variants to handle large datasets.

Results: Experiments on benchmark datasets—including handwritten digits, image patches, and biomedical signals—demonstrate that STM achieves up to 12% higher classification accuracy than unsupervised SOM and comparable or better performance than standard supervised dimensionality‐reduction techniques. Visualization metrics such as topology preservation index and cluster purity also improve substantially, indicating clearer separation of class regions on the map.

Conclusion: By seamlessly uniting topology‐preserving mapping with supervision, STM offers an interpretable low‐dimensional representation that benefits both exploratory analysis and downstream classification tasks. Its flexible design allows adaptation to diverse data modalities, making it a promising tool for pattern recognition, anomaly detection, and visual analytics.  
Keywords: supervised topological map, Self-Organizing Map, dimensionality reduction, data visualization, classification, topology preservation.
