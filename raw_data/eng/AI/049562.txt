Object detection requires accurate classification and precise localisation, yet most loss functions treat these tasks independently, leading to suboptimal performance. This paper introduces a novel ranking-based, balanced loss function that unifies classification and localisation within a single, coherent framework. Our approach leverages a ranking mechanism to prioritise high-quality detections during training, effectively addressing the class imbalance problem and mitigating the influence of inaccurate bounding box predictions. The proposed loss function incorporates adaptive weighting to dynamically balance the contributions of classification and localisation errors based on the ranking score. We evaluate our method on benchmark datasets, including COCO and Pascal VOC, demonstrating significant improvements in average precision and localisation accuracy compared to state-of-the-art object detection models using conventional loss functions. The results indicate that our unified ranking-based approach effectively promotes harmonious learning between classification and localisation, leading to enhanced object detection performance. Keywords: object detection, loss function, ranking, classification, localisation, computer vision.
