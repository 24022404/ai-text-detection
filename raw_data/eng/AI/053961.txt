Unsupervised object segmentation remains a challenging task in computer vision due to the absence of labeled data. This paper introduces DyStaB, a novel Dynamic-Static Bootstrapping framework for unsupervised object segmentation. DyStaB leverages the motion information in video sequences to generate pseudo-labels, treating moving regions as dynamic objects and static background as context. A dynamic segmentation network is trained on these pseudo-labels. To refine the segmentation results and address noisy pseudo-labels, we introduce a static segmentation network, which learns complementary information from appearance cues. The dynamic and static networks iteratively bootstrap each other, progressively improving segmentation accuracy. Experiments on standard benchmark datasets demonstrate that DyStaB achieves state-of-the-art performance compared to existing unsupervised object segmentation methods. The proposed approach significantly reduces the reliance on manual annotations, offering a practical solution for object segmentation in scenarios where labeled data is scarce. Keywords: Unsupervised Object Segmentation, Video Segmentation, Dynamic Segmentation, Static Segmentation, Bootstrapping, Computer Vision.
