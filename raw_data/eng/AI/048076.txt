This paper introduces Points2Vec, a novel unsupervised learning framework for extracting object-level feature representations directly from 3D point clouds. The objective is to learn meaningful features without relying on labeled data, addressing a critical need in 3D scene understanding. Our approach leverages a contrastive learning strategy combined with a hierarchical point cloud processing network based on PointNet++. Specifically, we generate positive and negative sample pairs by applying geometric transformations and introduce a novel point cloud augmentation technique to enhance the robustness of learned features. The framework is trained to discriminate between these pairs, forcing the network to learn discriminative and invariant feature embeddings. Evaluation on several benchmark datasets for 3D object classification and retrieval demonstrates that Points2Vec achieves competitive performance compared to state-of-the-art unsupervised methods and even approaches the performance of some supervised learning techniques. The learned features exhibit strong generalization capabilities, making them suitable for various downstream tasks. These findings highlight the potential of unsupervised learning for representation learning on point cloud data, reducing the dependence on large labeled datasets.
**Keywords:** Point cloud, unsupervised learning, feature extraction, 3D object recognition, contrastive learning, representation learning.
