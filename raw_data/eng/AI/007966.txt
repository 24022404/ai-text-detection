Unsupervised Domain Adaptation (UDA) for object detection aims to transfer knowledge from a labeled source domain to an unlabeled target domain. Existing methods rely on accessing source data during adaptation, which may be restricted due to privacy concerns or data accessibility issues. This paper addresses a novel and practical scenario: Source-Free UDA object detection, where the source data is unavailable. We propose a novel framework, named SF-UDAD, that leverages only a pre-trained source model and unlabeled target data for adaptation. SF-UDAD employs a self-training strategy guided by a pseudo-label filtering mechanism to generate reliable target domain annotations. Furthermore, we introduce a feature alignment module based on adversarial learning, focusing on aligning domain-invariant features to bridge the source and target domain gap. Experiments on multiple benchmark datasets demonstrate that SF-UDAD achieves competitive performance compared to existing UDA methods that require source data, offering a practical "free lunch" for domain adaptive object detection. Our approach enables effective adaptation in scenarios where source data is inaccessible, significantly expanding the applicability of UDA object detection. Keywords: Unsupervised Domain Adaptation, Object Detection, Source-Free Domain Adaptation, Self-Training, Adversarial Learning.
