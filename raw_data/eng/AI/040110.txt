Heterogeneous graphs, characterized by diverse node and edge types, are prevalent in complex information systems such as social networks, citation databases, and recommendation platforms. However, learning effective and universal node embeddings across these varied structures poses significant challenges due to semantic complexity and structural diversity. This paper presents PanRep, a novel graph neural network (GNN) framework designed to extract universal node embeddings from heterogeneous graphs. PanRep introduces a unified representation learning approach that leverages type-aware aggregation mechanisms, enabling effective integration of heterogeneous node and edge features within a single embedding space. The framework employs adaptive message-passing strategies and dynamic weighting to capture multi-relational information, ensuring both node-level discrimination and generalizability. Experimental evaluation on several real-world heterogeneous graph datasets demonstrates that PanRep consistently outperforms state-of-the-art methods in tasks such as node classification, link prediction, and clustering, achieving higher accuracy and better scalability. The proposed approach not only enhances task-specific performance but provides a versatile, transferable embedding framework for a wide range of downstream graph analytics. These results highlight the value of universal node embeddings and mark a significant step towards more generalizable graph representation learning. Keywords: heterogeneous graphs, graph neural networks, node embeddings, representation learning, multi-relational graphs, universal embedding.
