Abstract:

Instance segmentation is a fundamental task in computer vision that involves identifying and delineating each object instance within an image. Traditional embedding-based approaches often assume a fixed or unknown number of clusters, which can lead to suboptimal performance in scenarios with variable and complex object counts. This paper introduces a novel instance segmentation framework that explicitly incorporates the known or estimated number of clusters—corresponding to object instances—into the embedding learning process. The proposed method integrates a dynamic clustering mechanism with deep embedding learning, enabling the network to produce more discriminative instance representations tailored to the actual number of objects in the scene. Experimental evaluations on standard benchmarks demonstrate that our approach outperforms conventional methods, yielding higher segmentation accuracy and more robust instance separation, particularly in crowded or overlapping object environments. The results highlight the benefits of aligning embedding spaces with cluster cardinality, leading to improved adaptability and generalization. This research contributes to the advancement of instance segmentation by proposing a cluster-aware embedding learning strategy, with potential applications in autonomous vehicles, robotics, and scene understanding. Keywords: instance segmentation, cluster-aware embedding, deep learning, dynamic clustering, computer vision.
