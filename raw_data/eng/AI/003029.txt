Object detection is traditionally approached with specialized architectures and hand-designed pipelines. This paper introduces Pix2seq, a novel object detection framework that reframes the task as a language modeling problem. Instead of directly predicting bounding boxes and class labels, Pix2seq serializes object detection outputs (e.g., bounding box coordinates and class names) into a sequence of discrete tokens. An autoregressive model is then trained to generate this sequence conditioned on the input image pixels. This approach eliminates the need for task-specific layers, non-maximum suppression, and anchor boxes. We evaluate Pix2seq on the COCO dataset, demonstrating competitive performance compared to existing object detectors, particularly in handling objects with complex relationships. The results highlight the potential of language modeling for object detection and provide a new perspective on representing and reasoning about visual information. Keywords: Object Detection, Language Modeling, Sequence Generation, Autoregressive Models, Pix2seq.
