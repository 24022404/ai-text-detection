Unsupervised Domain Adaptation (UDA) in object detection seeks to improve model performance on a target domain that differs from the labeled source domain, typically by transferring knowledge from the source. However, existing approaches generally require direct access to source domain data during adaptation, raising concerns over data privacy, storage, and transfer restrictions. This paper addresses the challenge of source-free unsupervised domain adaptive object detection by proposing a novel framework that eliminates the need for source data at adaptation time. Our method leverages a pre-trained source model and introduces a set of unsupervised techniques, such as target-domain pseudo-labeling, feature-level normalization, and self-training with confidence thresholding, to align the model to the target domain using only unlabeled target images. Experimental results on benchmark datasets demonstrate that our approach achieves competitive or superior performance compared to traditional source-dependent UDA methods, without incurring additional resource consumption or compromising data security. The proposed framework offers a practical and efficient solution for real-world deployment of object detection systems across diverse domains where source data is inaccessible. This work underscores the potential for scalable, privacy-preserving domain adaptation in computer vision, particularly in scenarios involving sensitive or proprietary datasets. Keywords: unsupervised domain adaptation, source-free, object detection, self-training, domain generalization, transfer learning.
