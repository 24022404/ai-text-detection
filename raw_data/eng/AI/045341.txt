Unsupervised domain translation aims to learn mappings between different data domains without explicit paired examples. This paper addresses the challenge of adapting a domain translator trained on a source domain to effectively translate data from unseen target domains. We introduce a novel meta-learning framework, Learning to Transfer (L2T), which enables a domain translation model to quickly adapt to new target domains using only unpaired data. L2T trains a meta-translator to learn domain-invariant representations and a domain-specific adaptation module. The adaptation module is optimized to minimize a reconstruction loss on the target domain data, enabling rapid adaptation. Experimental results on benchmark datasets demonstrate that L2T significantly improves the performance of unsupervised domain translation on unseen target domains, outperforming existing meta-learning and domain adaptation techniques. The proposed method facilitates flexible and efficient domain translation, offering a promising direction for generalizing domain adaptation models to novel environments. Key words: unsupervised domain translation, meta-learning, domain adaptation, neural networks, unsupervised learning.
