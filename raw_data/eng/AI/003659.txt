Node representation learning aims to embed graph nodes into a low-dimensional space while preserving the graph's structural information. This paper rethinks the application of kernel methods, a traditionally powerful tool in machine learning, for node representation learning. We introduce a novel framework that leverages kernel functions to capture complex relationships between nodes, moving beyond the limitations of existing methods that primarily rely on network proximity or structural similarity. Our approach defines a graph kernel based on random walk kernels, capturing long-range dependencies efficiently. Furthermore, we develop an efficient approximation technique using Nyström sampling to scale kernel computation to large graphs. Experiments on benchmark datasets demonstrate that our method achieves competitive performance in node classification and link prediction tasks compared to state-of-the-art graph neural networks and matrix factorization techniques, while offering theoretical guarantees and interpretability benefits inherent to kernel methods. This work provides a new perspective on graph representation learning, highlighting the potential of kernel methods for capturing intricate graph structures.

**Keywords:** Node Representation Learning, Kernel Methods, Graph Kernels, Random Walks, Nyström Approximation, Graph Embedding.
