Object detection in aerial images presents unique challenges due to variations in object scale, orientation, and viewpoint. To address the limitations of existing datasets, we introduce DOTA (Dataset for Object deTection in Aerial images), a large-scale, high-resolution dataset for object detection in aerial images. DOTA contains 2,806 aerial images, each approximately 4000×4000 pixels in size, and 188,282 object instances annotated with arbitrary (8 degrees of freedom) quadrilaterals. These instances cover 15 common object categories. We employ a hierarchical annotation strategy to ensure annotation accuracy and consistency. Comprehensive experiments using state-of-the-art object detection methods demonstrate that DOTA presents significant challenges for current algorithms. The size, diversity, and annotation style of DOTA will facilitate the development of more robust and accurate object detectors for aerial images. The DOTA dataset and its associated evaluation toolkit are publicly available to the research community.
Keywords: object detection, aerial images, remote sensing, large-scale dataset, arbitrary quadrilaterals.
