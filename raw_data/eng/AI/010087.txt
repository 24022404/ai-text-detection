Incremental learning allows models to adapt to new data without forgetting previously learned knowledge, a crucial capability for real-world applications. This paper introduces DeeSIL, a novel Deep-Shallow Incremental Learning framework designed to improve the stability-plasticity dilemma inherent in deep neural networks. DeeSIL utilizes a deep network to learn complex feature representations and a shallow network for efficient knowledge consolidation. The deep network focuses on learning new information, while the shallow network acts as a memory module, preserving knowledge from previous tasks. An adaptive knowledge distillation strategy transfers crucial information from the deep network to the shallow network, mitigating catastrophic forgetting. We evaluate DeeSIL on several benchmark image classification datasets, demonstrating superior performance compared to existing incremental learning methods in terms of accuracy, forgetting rate, and computational efficiency. Specifically, DeeSIL achieves state-of-the-art results while requiring fewer parameters and training time. This approach provides a practical solution for deploying deep learning models in dynamic environments where data distributions evolve over time.

Keywords: Incremental Learning, Catastrophic Forgetting, Deep Learning, Knowledge Distillation, Neural Networks.
