This paper presents a compressed object detection model based on YOLOv4, specifically designed for deployment on embedded GPU platforms within autonomous systems. The objective is to address the computational demands of real-time object detection while maintaining accuracy on resource-constrained devices. Our approach involves applying knowledge distillation and network pruning techniques to reduce the model size and computational complexity of the original YOLOv4 architecture. Experimental results demonstrate that the compressed model achieves a significant reduction in model size (approximately 60%) and inference time (approximately 40%) compared to the standard YOLOv4, with only a marginal decrease in mean Average Precision (mAP) on the COCO dataset. The compressed model’s performance is evaluated on an NVIDIA Jetson embedded GPU platform, showcasing its feasibility for real-time object detection in autonomous applications. This work contributes a practical solution for deploying accurate and efficient object detection capabilities on embedded systems, enabling enhanced perception in autonomous navigation, robotics, and surveillance. Keywords: Object Detection, YOLOv4, Model Compression, Embedded GPU, Autonomous Systems, Knowledge Distillation, Network Pruning.
