**Abstract**

Optimizing compiler performance is a critical aspect of software development, yet traditional heuristic-based approaches often struggle to adapt to diverse programs and hardware architectures. This paper presents a novel framework for static neural compiler optimization leveraging deep reinforcement learning (DRL). Our approach models the optimization selection process as a sequential decision-making problem, where a neural agent learns to map program features to optimal transformation sequences without requiring runtime feedback. We employ a deep neural network as the policy function, trained using simulated execution rewards derived from static code analysis and profiling data. Experimental evaluations on standard compiler benchmarks demonstrate that our method outperforms classical static optimization heuristics and several recent learning-based baselines in terms of execution speed and code size reduction. Notably, the DRL-based optimizer exhibits strong generalization to previously unseen program types and architectures. These findings indicate that deep reinforcement learning offers a powerful, adaptable tool for static compiler optimization, with significant implications for automating software performance tuning and enhancing cross-platform development. Keywords: compiler optimization, deep reinforcement learning, neural networks, static analysis, program optimization, automated code tuning.
