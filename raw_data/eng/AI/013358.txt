The "View Dynamic Analysis Report" sub-use case enables users to access a detailed report that summarizes the outcomes of dynamic analysis conducted on an uploaded Android application. This report provides comprehensive insights into various observed behaviors throughout the app’s execution, such as API calls made, network requests initiated, file system interactions, and permission usage. Additionally, it highlights significant actions, potential security risks, and any suspicious activities detected during runtime. To utilize this functionality, users must ensure that the Android application file has been uploaded and the analysis process has been completed beforehand.
