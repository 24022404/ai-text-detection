Automated game testing is crucial for efficient software development, yet current methods often struggle with unpredictable game environments and complex player behaviors. This paper introduces a novel approach that augments traditional automated game testing using deep reinforcement learning (DRL). We developed an intelligent agent, trained via DRL, capable of exploring game environments, identifying critical bugs, and uncovering emergent gameplay scenarios more effectively than conventional scripted tests or random exploration techniques. Our methodology employs a customized reward function that incentivizes the agent to maximize code coverage and discover game-breaking issues. We evaluate our approach on a suite of benchmark game levels, demonstrating a significant improvement in bug detection rate and code coverage compared to state-of-the-art testing methods. Furthermore, the DRL agent successfully identified previously unknown exploits and emergent behaviors. The findings suggest that DRL can significantly enhance automated game testing, leading to more robust and engaging game experiences. Keywords: Deep Reinforcement Learning, Automated Game Testing, AI Agent, Bug Detection, Code Coverage, Emergent Behavior.
