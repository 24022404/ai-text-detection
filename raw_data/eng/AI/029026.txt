Graph embedding, a technique that maps nodes into a low-dimensional space while preserving structural information, is fundamental to various network analysis tasks. However, existing methods often struggle with noisy or incomplete graph data, leading to suboptimal representations. This paper introduces RECS (Robust Embedding using Connection Subgraphs), a novel graph embedding approach that enhances robustness by leveraging connection subgraphs. RECS constructs multiple local subgraphs centered around each node, capturing diverse relational contexts and mitigating the impact of spurious edges. We propose a joint embedding framework that learns node representations by aggregating information from these subgraphs, enforced through a subgraph consistency loss. Experiments on several benchmark datasets demonstrate that RECS consistently outperforms state-of-the-art methods in node classification, link prediction, and graph visualization tasks, particularly in the presence of significant noise. The results highlight RECS's ability to learn robust and informative node embeddings, offering a significant advancement for network analysis applications.
Keywords: Graph Embedding, Network Analysis, Robustness, Subgraphs, Node Representation Learning, Machine Learning.
