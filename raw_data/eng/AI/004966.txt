X-ray security inspection plays a vital role in public safety, yet the detection of prohibited items is challenged by occlusion and the similarity of objects. This paper introduces a novel benchmark dataset, Occluded Prohibited Items (OPI), designed to specifically address the problem of occlusion in X-ray security imagery. The OPI dataset comprises diverse X-ray images with varying degrees of occlusion, reflecting real-world security scenarios. We propose a De-occlusion Attention Module (DAM) to enhance feature representation in occluded regions. DAM leverages spatial attention mechanisms to re-weight features, effectively suppressing irrelevant information from occluding objects and highlighting features of the occluded prohibited items. Experimental results on the OPI benchmark demonstrate that the proposed DAM significantly improves detection accuracy, particularly for highly occluded items, outperforming state-of-the-art object detection methods. The OPI dataset and DAM contribute to advancing research in occluded object detection for security applications, offering a practical solution to improve the effectiveness of X-ray security screening.
Keywords: X-ray Security Inspection, Object Detection, Occlusion, Attention Mechanism, Benchmark Dataset.
