This paper introduces DRIFT, a novel framework leveraging Deep Reinforcement Learning (DRL) techniques to advance the field of functional software testing. Traditional automated software testing approaches often struggle to effectively explore complex input spaces, resulting in suboptimal test coverage and undetected bugs. To address these challenges, DRIFT formulates the testing process as a Markov Decision Process and utilizes modern DRL algorithms to dynamically generate test cases that adapt based on feedback from code execution. The proposed method integrates a neural network-based policy model to learn exploration strategies that maximize code coverage and defect discovery over time. In extensive experiments on open-source software systems, DRIFT demonstrated significantly higher efficiency and bug-detection rates compared to conventional random and model-based testing frameworks. Furthermore, DRIFT’s adaptive mechanism allows for continuous improvement as testing progresses, making it highly suitable for real-world, large-scale software systems. The main contributions of this research include the development of an end-to-end DRL-based test generation pipeline, a detailed evaluation on diverse benchmarks, and analysis of DRL’s effectiveness in functional testing scenarios. These results underscore the potential of deep reinforcement learning to transform automated software testing, enhancing software quality and reliability. Keywords: deep reinforcement learning, functional testing, software testing automation, neural networks, code coverage.
