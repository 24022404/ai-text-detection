The increasing reliance on machine learning models in critical applications has raised significant concerns regarding model verification and authorization. Traditional methods often lack robust mechanisms to ensure that only authorized users can access or deploy specific models. This paper introduces *Non-Transferable Learning* (NTL), a novel approach designed to address these challenges by embedding unique, non-transferable identifiers into machine learning models during training. The proposed method leverages cryptographic principles and model-specific perturbations to create a verification mechanism that ensures only authorized users can utilize the model effectively. We present a comprehensive framework for implementing NTL, including the design of the embedding process, verification protocols, and robustness against adversarial attacks. Experimental results demonstrate that NTL achieves high verification accuracy (over 98%) while maintaining model performance on benchmark datasets. Furthermore, the approach is shown to be resilient against model extraction and unauthorized redistribution attempts. This work contributes a scalable and secure solution for model authorization, with potential applications in intellectual property protection, secure AI deployment, and controlled access to proprietary models. Keywords: Non-Transferable Learning, Model Verification, Authorization, Machine Learning Security, Cryptographic Embedding.
