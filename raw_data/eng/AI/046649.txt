The deployment of object detection models on resource-constrained embedded GPU platforms for autonomous systems presents significant challenges due to computational and memory limitations. This paper addresses the need for efficient and lightweight object detection by proposing a compressed version of the YOLOv4 model, optimized for embedded GPU deployment. The objective is to achieve real-time performance while maintaining high detection accuracy. To accomplish this, we employ a combination of model pruning, quantization, and knowledge distillation techniques, reducing the model's size and computational complexity without compromising its effectiveness. The proposed approach is evaluated on standard datasets, demonstrating a significant reduction in model parameters and inference time compared to the original YOLOv4, while achieving competitive accuracy metrics. Results indicate that the compressed model achieves a 40% reduction in model size and a 35% improvement in inference speed, making it suitable for real-time applications on embedded systems. The study concludes that the proposed method offers a practical solution for deploying advanced object detection capabilities in autonomous systems, such as drones and robotics, where computational efficiency is critical. This work contributes to the growing field of edge AI by providing a novel framework for optimizing deep learning models for embedded platforms.  

**Keywords**: YOLOv4, object detection, model compression, embedded GPU, autonomous systems, edge AI, real-time processing.
