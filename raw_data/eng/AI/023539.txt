Object detection is a critical component of autonomous driving systems, impacting perception accuracy and overall safety. This paper addresses two key challenges in object detection: suboptimal anchor generation and class imbalance. We propose a novel anchor generation strategy based on k-means clustering applied to ground truth bounding box statistics, enabling more effective coverage of object shapes and sizes within a scene. Furthermore, we introduce a dynamic weighting loss function that adaptively adjusts the penalty for misclassifications based on class frequency, mitigating the impact of class imbalance. We evaluate our approach on the challenging KITTI dataset, demonstrating significant improvements in Average Precision (AP) across various object categories, including a 5% increase in AP for pedestrians and a 3% increase for vehicles compared to state-of-the-art methods. These results indicate that optimized anchor generation coupled with dynamic loss weighting significantly enhances object detection performance in autonomous driving scenarios, leading to safer and more reliable autonomous systems. Keywords: Object Detection, Autonomous Driving, Anchor Generation, Class Imbalance, Deep Learning, KITTI.
