This paper introduces PyKEEN 1.0, a comprehensive Python library designed to facilitate the training and evaluation of knowledge graph embedding (KGE) models. Knowledge graph embeddings are crucial for representing large, complex relational data in a continuous vector space, enabling applications such as link prediction, entity classification, and data integration. PyKEEN 1.0 addresses the growing need for a unified, extensible, and user-friendly framework that supports a wide range of KGE algorithms and evaluation protocols. The library implements a modular design, allowing researchers and practitioners to easily train, test, and benchmark various embedding models across multiple datasets. PyKEEN 1.0 offers robust support for hyperparameter optimization, reproducible experiments, and extensible pipeline components, which streamline the development and comparison of new approaches. Experimental results demonstrate that PyKEEN 1.0 achieves competitive performance with state-of-the-art models, while significantly reducing the effort required for experimentation and deployment. The library’s flexibility, well-documented APIs, and active community contributions make it a valuable resource for both academic research and practical applications in knowledge graph analytics. Keywords: knowledge graph embeddings, Python library, link prediction, entity classification, KGE models, machine learning, open-source software.
