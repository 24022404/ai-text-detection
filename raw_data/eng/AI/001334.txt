This paper introduces a novel semi-automated statistical algorithm for object separation in complex digital images. The primary objective is to improve the efficiency and accuracy of object segmentation, particularly in scenarios where fully automated methods struggle due to image noise or overlapping objects. Our approach combines initial user-defined seed points with an iterative statistical analysis of pixel characteristics, including color and texture. The algorithm refines object boundaries by modeling the statistical distribution of each object and iteratively assigning pixels based on maximum likelihood estimation. We demonstrate the effectiveness of the algorithm using a diverse set of images and benchmark its performance against existing automated and manual segmentation techniques. Results show a significant improvement in segmentation accuracy, achieving an average Dice coefficient of 0.85, while substantially reducing the required manual effort compared to fully manual methods. The developed algorithm offers a practical solution for applications requiring precise object separation, such as medical image analysis and satellite imagery processing. Key words: object separation, image segmentation, statistical algorithm, semi-automated, maximum likelihood estimation.
