Contrastive representation learning has emerged as a powerful paradigm for unsupervised feature extraction, yet challenges remain in effectively capturing local image structures and enhancing feature discriminability. This paper introduces *Center-wise Local Image Mixture (CLIM)*, a novel approach designed to improve contrastive learning by leveraging localized image regions and their semantic relationships. The proposed method dynamically identifies and mixes local image patches around key feature centers, enabling the model to learn more robust and discriminative representations. CLIM integrates a center-wise attention mechanism to prioritize semantically meaningful regions, coupled with a contrastive loss function tailored to optimize local feature alignment. Experiments conducted on benchmark datasets demonstrate that CLIM outperforms existing methods in downstream tasks such as image classification and object detection, achieving state-of-the-art performance with fewer training epochs. The results highlight the effectiveness of CLIM in enhancing feature learning by focusing on localized image semantics, offering a scalable and efficient solution for unsupervised representation learning. This work contributes to advancing contrastive learning techniques, with potential applications in computer vision, medical imaging, and autonomous systems.  

**Keywords**: Contrastive learning, local image representation, unsupervised learning, feature extraction, center-wise attention, image classification.
