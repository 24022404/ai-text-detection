OpenSpiel is a software framework designed to facilitate research in reinforcement learning and game theory. It provides a collection of environments implementing various games, both classical and contemporary, alongside tools for analysis and algorithm development. This paper introduces OpenSpiel's architecture, emphasizing its flexibility in representing diverse game types, including simultaneous-move, imperfect-information, and multiplayer games. The framework offers a unified API for developing and evaluating reinforcement learning agents across these diverse environments. We demonstrate the utility of OpenSpiel by benchmarking several established reinforcement learning algorithms on a suite of games, highlighting their performance and limitations. Furthermore, we present novel algorithms developed using OpenSpiel for solving specific game classes, demonstrating the framework's extensibility. OpenSpiel aims to lower the barrier to entry for researchers in reinforcement learning and game theory, fostering the development of more robust and general-purpose algorithms. Key words: reinforcement learning, game theory, open-source, framework, multi-agent, environment.
