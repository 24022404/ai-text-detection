Single-shot object detection has gained significant attention due to its efficiency in real-time applications. However, achieving high accuracy while maintaining computational efficiency remains a challenge, particularly in handling scale variations and complex backgrounds. This paper introduces the Feature Selective Anchor-Free (FSAF) module, a novel approach designed to enhance the performance of single-shot object detectors. The FSAF module operates by dynamically selecting optimal feature levels for each object instance, eliminating the need for predefined anchor boxes and reducing computational overhead. We integrate the FSAF module into a state-of-the-art single-shot detection framework and evaluate its performance on benchmark datasets, including COCO and PASCAL VOC. Experimental results demonstrate that the proposed method achieves superior detection accuracy compared to existing anchor-based and anchor-free approaches, with significant improvements in handling small and occluded objects. The FSAF module also exhibits robustness across diverse object scales and complex scenes, making it a promising solution for real-world applications. This work contributes to advancing single-shot object detection by introducing a lightweight, efficient, and scalable module that bridges the gap between accuracy and computational efficiency.  

**Keywords**: Single-shot object detection, anchor-free, feature selection, real-time detection, scale variation, computational efficiency.
