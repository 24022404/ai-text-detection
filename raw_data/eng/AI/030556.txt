This paper presents a novel approach to scene graph-to-image generation, focusing on refining object layouts through contextualization. The objective is to enhance the realism and coherence of generated images by improving the spatial arrangement of objects within a scene. Our method employs a graph convolutional network to learn contextual relationships between objects, which informs a refinement module that adjusts object positions and orientations. The results demonstrate significant improvements in image quality and object placement accuracy compared to existing methods. Notably, our approach achieves state-of-the-art performance on benchmark datasets, with generated images exhibiting more realistic and contextually appropriate object layouts. The contributions of this research lie in its ability to effectively model complex object relationships and refine layouts to create more convincing and detailed scenes. Key applications of this work include image synthesis, data augmentation, and computer vision tasks such as object detection and scene understanding, with relevant keywords including scene graph, image generation, object layout refinement, graph convolutional networks, and computer vision.
