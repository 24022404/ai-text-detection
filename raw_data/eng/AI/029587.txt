Object detection is a pivotal task in computer vision, traditionally addressed using dense sets of proposals that can lead to high computational costs and less efficient training. This paper presents Sparse R-CNN, an end-to-end object detection framework that employs a limited number of learnable object proposals, moving away from the conventional use of region proposal networks and dense anchor points. The proposed approach introduces a sparse set of proposal boxes that are optimized during training to focus on potential object regions, allowing the detector to concentrate computational resources on relevant image areas. We implement a transformer-based architecture that iteratively refines both the object proposals and their corresponding features, enabling robust object localization and classification. Experimental results on benchmarks such as COCO demonstrate that Sparse R-CNN achieves state-of-the-art detection accuracy while significantly reducing the number of proposals and computational overhead compared to traditional detectors. Our findings indicate that learnable proposals can effectively capture diverse object instances with fewer computational resources, making Sparse R-CNN suitable for real-time and resource-constrained applications. This study highlights the advantages of sparse proposal mechanisms and sets a new direction for efficient object detection frameworks.  
Keywords: object detection, Sparse R-CNN, learnable proposals, deep learning, transformer, computer vision, end-to-end detection.
