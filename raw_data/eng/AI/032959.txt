Instance segmentation, a critical task in computer vision, aims to precisely delineate and classify individual objects within an image. Traditional mask representations often rely on pixel-level or polygon-based approaches, which can be computationally expensive and memory-intensive. This paper introduces **DCT-Mask**, a novel framework that leverages the Discrete Cosine Transform (DCT) to represent instance masks efficiently. By encoding masks in the frequency domain, DCT-Mask significantly reduces memory usage while maintaining high segmentation accuracy. The proposed method integrates DCT-based mask compression with a state-of-the-art instance segmentation model, enabling real-time performance on resource-constrained devices. Experimental results on benchmark datasets demonstrate that DCT-Mask achieves competitive segmentation accuracy compared to existing methods, with a 40% reduction in memory footprint. Furthermore, the framework exhibits robustness across diverse object shapes and scales, making it suitable for applications in autonomous driving, medical imaging, and robotics. The key contribution of this work lies in its innovative use of frequency-domain representations for instance segmentation, offering a balance between computational efficiency and performance. DCT-Mask paves the way for deploying advanced segmentation models in edge computing environments, where resource efficiency is paramount.  

**Keywords**: Instance segmentation, Discrete Cosine Transform (DCT), mask representation, frequency domain, memory efficiency, real-time processing.
