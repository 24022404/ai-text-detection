Sparse object detection, where only a small subset of objects in an image are labeled, poses a significant challenge for existing object detection models. This paper introduces Detective, an attentive recurrent model designed to effectively address this challenge. Detective leverages a recurrent neural network (RNN) architecture to sequentially process image regions, focusing on areas likely to contain objects based on attention mechanisms. Specifically, the model learns to attend to informative regions using contextual information from previously detected objects, enabling it to efficiently identify sparsely labeled objects. We evaluate Detective on benchmark datasets with varying levels of sparsity and demonstrate that it outperforms state-of-the-art object detection methods, particularly in scenarios with extremely limited labeled data. Our results indicate that Detective can achieve a 15% improvement in average precision compared to existing methods when only 10% of objects are labeled. The proposed attentive recurrent approach offers a promising direction for improving object detection performance in sparse annotation scenarios, reducing the reliance on large, fully labeled datasets. Keywords: object detection, sparse labels, recurrent neural network, attention mechanism, deep learning.
