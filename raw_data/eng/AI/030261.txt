The system architecture, as outlined in Figure 4.1, demonstrates a modern, scalable approach to web application design. At the frontend, both admin and user interfaces are developed using ReactJs, allowing for a dynamic and responsive user experience. State management is efficiently handled through redux-saga, enabling robust handling of asynchronous flows and facilitating seamless interaction with the backend through well-structured REST APIs. Performance optimization is achieved by loading components on demand, ensuring that resources are utilized only when necessary, which reduces initial load times and enhances the overall responsiveness of the application. To improve and streamline the communication between the frontend and backend, a custom tool was engineered specifically to handle API interactions, ensuring reliability and flexibility. On the backend, the architecture adheres to a microservices paradigm, featuring 11 independently functioning services, each responsible for managing its distinct PostgreSQL table. These services are coordinated by a central gateway service developed with Java Spring Boot, which acts as the main interface for the frontend and orchestrates interactions between the microservices. Kafka queues serve as the backbone for inter-service messaging and event-driven communication, promoting scalability and data consistency. To accelerate data retrieval and reduce database load, Redis is integrated as a caching solution. The complete system, including all backend services and dependencies, is containerized using Docker and orchestrated via docker-compose, significantly simplifying environment management for both development and deployment. For frontend aesthetics and usability, Antd is employed, offering highly customizable and visually appealing interface components.
