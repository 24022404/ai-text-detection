Object detection has been dominated by methods relying on dense object proposals, which often lead to high computational costs and redundancy. This paper introduces Sparse R-CNN, an end-to-end object detector that learns sparse, learnable proposal boxes directly from the data, eliminating the need for predefined anchor boxes or region proposals. The model comprises a learnable proposal box set and a learnable proposal feature embedding set. Through iterative interaction with the CNN backbone, these sparse proposals are refined into accurate object detections. We demonstrate that by decoupling object classification and localization, Sparse R-CNN avoids the need for complex matching operations and non-maximum suppression. Experiments on the COCO dataset show that Sparse R-CNN achieves competitive performance compared to state-of-the-art dense proposal methods, while significantly reducing computational complexity. The proposed approach offers a novel and efficient alternative for object detection, with potential applications in real-time systems and resource-constrained environments. Keywords: Object Detection, Sparse R-CNN, Learnable Proposals, End-to-End Learning, Computer Vision.
