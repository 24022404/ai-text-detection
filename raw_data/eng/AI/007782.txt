Objective: Learning from sequence and time-series data is fundamental across domains such as sensor analytics, finance, and biomedical monitoring, yet general-purpose machine learning libraries offer limited, fragmented support for these tasks. We introduce seglearn, an open-source Python package that extends the familiar scikit-learn API to streamline sequence and time-series classification, regression, and segmentation.

Methods/Approach: seglearn provides modular tools for sliding-window segmentation, on-the-fly feature extraction, and direct sequence modeling. Its pipeline architecture integrates transformers for signal preprocessing (normalization, resampling), feature calculators (statistical, spectral, domain-specific), and estimators—including scikit-learn classifiers/regressors and Keras neural networks—under a unified interface. Data splitting routines respect temporal dependencies, and parallel execution is supported to accelerate large-scale experiments.

Results/Findings: In empirical evaluations on benchmark datasets for human activity recognition and physiological signal classification, seglearn pipelines achieved classification accuracies on par with specialized libraries, while reducing code complexity by over 50%. Feature extraction modules processed multi-channel recordings at interactive speeds, and end-to-end workflows—from raw sequence input to cross-validated performance metrics—were reproducible with minimal configuration.

Conclusion/Implications: seglearn fills a critical gap by delivering a consistent, extensible framework for sequence-based machine learning in Python. Its compliance with scikit-learn standards promotes rapid prototyping, reproducibility, and interoperability with existing tools, making it an ideal choice for researchers and practitioners tackling time-series challenges.

Keywords: seglearn, time series, sequence learning, Python, scikit-learn, sliding window segmentation, feature extraction, machine learning
