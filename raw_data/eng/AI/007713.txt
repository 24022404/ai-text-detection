Event-based data, characterized by high temporal resolution and asynchronous nature, pose significant challenges for traditional synchronous and supervised learning approaches. This paper proposes Event-LSTM, an unsupervised and asynchronous learning-based representation model specifically designed for processing event-based data streams. Our approach leverages a modified Long Short-Term Memory (LSTM) architecture that inherently handles the irregular arrival of events, enabling efficient temporal feature extraction without the need for annotated datasets. We introduce a novel temporal encoding mechanism that captures fine-grained event dynamics, ensuring robust representation of sparse and rapidly changing data. Experimental evaluations on benchmark event-based datasets demonstrate that Event-LSTM achieves superior performance in tasks such as event classification and anomaly detection, outperforming existing recurrent neural network architectures and unsupervised learning methods in both accuracy and processing latency. The results highlight the system’s robustness to noise and scalability to large-scale, real-time event streams. Event-LSTM’s unsupervised and asynchronous nature allows for practical deployment in resource-constrained and latency-critical applications, including neuromorphic vision, Internet of Things (IoT) sensor networks, and real-time anomaly monitoring. This work introduces a novel framework for event-based representation learning, contributing an effective solution for asynchronous data analysis in a wide range of AI-driven applications. **Keywords:** event-based data, unsupervised learning, asynchronous processing, LSTM, temporal representation, real-time systems, anomaly detection.
