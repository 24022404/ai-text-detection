Object detection models typically require large annotated datasets and struggle to adapt to new object categories with limited data, posing significant challenges in dynamic real-world environments. This paper addresses these limitations by introducing a novel Incremental Few-Shot Object Detection framework, designed to efficiently learn new object classes from minimal labeled examples without forgetting previously acquired knowledge. Our approach integrates incremental learning techniques with few-shot learning paradigms to enable seamless and scalable model updates. The proposed method employs a meta-learning backbone for rapid feature adaptation, combined with a memory-based consolidation module to minimize catastrophic forgetting during the introduction of new categories. Extensive experiments on benchmark object detection datasets demonstrate that our framework outperforms existing methods in both detection accuracy and stability across incremental learning sessions. Furthermore, comparative analysis highlights the model’s ability to maintain high performance on previously learned classes while achieving robust detection on novel, low-sample categories. The results suggest significant advancements in practical applications such as robotics, surveillance, and autonomous systems where continuous learning from limited data is required. Keywords: few-shot learning, incremental learning, object detection, meta-learning, continual learning, computer vision.
