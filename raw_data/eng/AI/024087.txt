Multi-label classification, assigning multiple labels to a single instance, is crucial in various applications like image and text categorization. This paper addresses the challenge of effectively integrating information from diverse modalities for enhanced multi-label classification. We propose a novel approach, Cross-Modality Attention with Semantic Graph Embedding (CMAGE), which leverages attention mechanisms to dynamically fuse features from different modalities (e.g., image and text). CMAGE constructs a semantic graph to capture the relationships between labels, embedding this graph structure into the learning process to improve label dependencies modeling. Specifically, the cross-modality attention module learns adaptive weights for each modality based on the input sample, while the semantic graph embedding module incorporates label correlations into the feature representation. Experiments on benchmark datasets demonstrate that CMAGE outperforms state-of-the-art multi-label classification methods, achieving significant improvements in precision, recall, and F1-score. The results highlight the effectiveness of dynamically integrating multi-modal features and explicitly modeling label dependencies through semantic graph embedding. This approach offers a promising direction for enhancing multi-label classification performance in complex, multi-modal scenarios.
Keywords: Multi-label classification, cross-modality attention, semantic graph embedding, multi-modal learning, label correlation.
