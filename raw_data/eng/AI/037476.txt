Understanding and inferring graph topology is a fundamental task in network science and various machine learning applications. Despite the existing methods and tools, there is a lack of standardized benchmarks to evaluate the effectiveness of machine learning algorithms in graph topology inference. This research addresses this gap by proposing comprehensive benchmarks tailored for assessing the performance of machine learning models in inferring graph topologies.

Methods/Approach: We developed a suite of benchmarks, encompassing various synthetic and real-world datasets, to evaluate graph topology inference methods. These benchmarks are designed to test different aspects of graph learning capabilities, including scalability, accuracy, and robustness. We incorporate state-of-the-art machine learning algorithms, with a focus on graph neural networks, to perform a detailed comparative study across the proposed benchmarks.

Results/Findings: Our experiments demonstrate significant variations in performance across different algorithms when applied to the benchmarks. Key findings reveal that certain architectures excel in specific tasks such as community detection or link prediction, while others offer superior performance in scalability tests. The results underscore the need for these benchmarks to facilitate algorithm selection and improvement in diverse application scenarios.

Conclusion/Implications: This research contributes a valuable resource for the machine learning community by providing structured benchmarks for graph topology inference. These benchmarks are instrumental in advancing the development and evaluation of machine learning models in this domain. Future work could explore the application of these benchmarks to emerging technologies and new types of graph data. Keywords: graph topology inference, machine learning, benchmarks, graph neural networks, network science.
