LiDAR-based object detection is crucial for autonomous driving, yet existing methods often process full LiDAR sweeps, introducing latency. This paper introduces StrObe, a novel streaming object detection framework that directly processes LiDAR packets as they arrive, enabling significantly lower latency. StrObe leverages a custom-designed, efficient point cloud accumulation strategy and a lightweight 3D object detection network tailored for streaming data. The method dynamically updates object detections with each incoming packet, progressively refining the results. Experimental evaluations on the nuScenes dataset demonstrate that StrObe achieves comparable accuracy to state-of-the-art sweep-based methods, while reducing latency by up to 5x. This reduced latency is vital for real-time decision-making in autonomous systems. The proposed streaming approach paves the way for more responsive and safer autonomous navigation.
Keywords: LiDAR, Object Detection, Streaming, Autonomous Driving, Real-time Processing, Low-latency.
