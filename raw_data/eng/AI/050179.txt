Functional software testing is crucial for ensuring software reliability, but traditional methods often struggle with complex systems and evolving requirements. This paper introduces DRIFT, a novel approach leveraging deep reinforcement learning (DRL) to automate and optimize functional software testing. DRIFT employs a DRL agent trained to generate test cases that maximize code coverage and identify potential bugs. The agent interacts with the software under test, learns from the feedback, and adapts its testing strategy accordingly. We propose a custom reward function that incentivizes exploration of diverse code paths and prioritizes the detection of critical failures. Experiments conducted on a suite of benchmark software projects demonstrate that DRIFT significantly outperforms traditional random testing and achieves comparable or superior performance to coverage-guided fuzzing techniques in terms of bug detection rate and code coverage. The results highlight the potential of DRL to enhance functional software testing, leading to more robust and reliable software systems. Keywords: Deep Reinforcement Learning, Software Testing, Functional Testing, Code Coverage, Bug Detection, Automation.
