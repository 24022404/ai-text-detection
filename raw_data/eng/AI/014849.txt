This paper addresses the challenge of enabling real-time object detection on edge devices operating under constrained and unreliable network conditions. The objective is to develop an efficient data transmission and processing framework that maintains high detection accuracy while reducing latency and bandwidth requirements. We propose a novel neural compression and filtering system that leverages deep learning techniques to selectively encode and transmit only the most relevant visual data from edge devices to remote detection servers. The approach combines a lightweight convolutional autoencoder for intra-frame compression with an adaptive filtering mechanism that prioritizes regions of interest based on preliminary objectness scores computed directly on the device. Extensive experiments were conducted on public object detection benchmarks under simulated low-bandwidth and high-latency scenarios to evaluate the framework’s effectiveness. Results demonstrate that the proposed system achieves up to a 70% reduction in transmitted data and a 30% decrease in detection latency, with negligible loss in detection accuracy compared to conventional edge-cloud pipelines. These findings highlight the potential of neural compression and smart data filtering to significantly improve the performance of edge-assisted real-time object detection, particularly in challenged network environments. The research contributes a scalable and adaptable solution that supports a range of applications, including intelligent surveillance, autonomous vehicles, and mobile augmented reality.  
Keywords: neural compression, edge computing, object detection, real-time processing, data filtering, challenged networks, deep learning, bandwidth optimization.
