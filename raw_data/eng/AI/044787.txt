This paper introduces AI Playground, a novel data ablation tool built within Unreal Engine for deep learning research. The tool facilitates controlled modification of synthetic datasets, enabling researchers to systematically analyze the impact of individual data features on model performance. AI Playground offers a user-friendly interface for manipulating scene parameters, object properties, and environmental conditions, automatically generating diverse datasets with corresponding ground truth annotations. Using AI Playground, we conducted experiments to assess the sensitivity of a segmentation model to variations in lighting, object texture, and camera angle. Results demonstrate the tool's effectiveness in identifying critical data characteristics that significantly influence model accuracy. We found that performance degradation was most pronounced when specific object textures were removed from the training data. This tool provides a valuable resource for understanding data dependencies in deep learning models and improving dataset design for enhanced generalization. Keywords: Data Ablation, Deep Learning, Unreal Engine, Synthetic Data, Dataset Analysis, Computer Vision.
