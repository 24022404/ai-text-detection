Event-based vision offers advantages over traditional frame-based cameras in high-speed and high dynamic range scenarios. This paper presents a novel moving object detection method tailored for event-based data using k-means clustering. Our approach leverages the asynchronous stream of events generated by moving objects to create spatiotemporal event clusters, which are then processed using k-means to differentiate between foreground and background events. By adapting k-means to the unique characteristics of event data, we achieve robust object detection without relying on explicit frame reconstruction. Experimental results on benchmark datasets demonstrate that our method achieves competitive performance in terms of accuracy and processing speed compared to existing event-based moving object detection algorithms. The proposed method offers a computationally efficient solution for real-time applications such as autonomous navigation and surveillance. Keywords: Event-based vision, moving object detection, k-means clustering, neuromorphic vision, asynchronous events.
