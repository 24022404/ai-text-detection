Object detection remains a critical and challenging task in computer vision. This paper introduces Reverse Connection with Objectness Prior Networks (RON), a novel architecture designed to enhance feature representation and improve object detection accuracy, particularly for small and occluded objects. RON leverages a top-down reverse connection pathway integrated with objectness prior guidance to effectively propagate contextual information and refine feature maps at each layer. Specifically, we generate objectness prior maps indicating the likelihood of an object being present, using a lightweight network, and then use these maps to guide the reverse feature fusion process. This allows the network to focus on informative regions and suppress background noise. Experimental results on benchmark datasets such as COCO demonstrate that RON significantly outperforms existing state-of-the-art object detection methods, especially in detecting small objects, while maintaining competitive computational efficiency. The proposed approach demonstrates robust performance in complex scenes with cluttered backgrounds and overlapping objects. Our work contributes a novel architecture that effectively integrates objectness prior information with reverse connection pathways to improve object detection performance. Keywords: Object Detection, Reverse Connection, Objectness Prior, Feature Fusion, Deep Learning, Computer Vision.
