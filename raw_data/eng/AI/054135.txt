Temporal network embedding aims to represent dynamic network structures in a low-dimensional space while preserving temporal dependencies. This paper introduces a novel approach to temporal network embedding based on tensor factorization. Our method decomposes a third-order tensor, representing the network's structure across different time steps, into latent factors capturing node representations and temporal dynamics. Specifically, we employ a CANDECOMP/PARAFAC (CP) decomposition to learn node embeddings that evolve smoothly over time, reflecting the network's evolving relationships. We evaluate our approach on several real-world dynamic network datasets, demonstrating superior performance compared to existing temporal network embedding techniques in tasks such as link prediction and node classification. Results show significant improvements in prediction accuracy and efficiency. The proposed method offers a scalable and effective solution for analyzing and understanding temporal networks, enabling applications in social network analysis, information diffusion modeling, and dynamic system monitoring.
Keywords: Temporal Network Embedding, Tensor Factorization, Dynamic Networks, Node Representation, Link Prediction.
