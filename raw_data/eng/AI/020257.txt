Accurate prediction of network device workload is essential for optimizing resource allocation and maintaining efficient network performance in modern IT infrastructures. This paper presents a novel lightweight model designed to forecast network device workload, prioritizing simplicity without compromising predictive accuracy. The proposed approach utilizes a minimal set of features and computationally efficient algorithms, enabling rapid deployment even on resource-constrained network hardware. Through extensive experiments using real-world traffic datasets, the lightweight model demonstrates comparable or superior accuracy relative to more complex, state-of-the-art machine learning models, while achieving significantly reduced computational overhead and latency. The results highlight the effectiveness of avoiding unnecessary model complexity, particularly for real-time applications and edge deployments where processing resources are limited. This research underscores the potential of streamlined models for practical workload prediction tasks in operational networks, contributing to improved scalability, energy efficiency, and lower maintenance costs. Keywords: workload prediction, lightweight model, network devices, resource efficiency, edge computing, real-time forecasting.
