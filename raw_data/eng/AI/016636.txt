Both the admin and user sites leverage ReactJS for constructing their interfaces, benefiting from React’s efficient rendering and component-driven architecture. To manage asynchronous data flow and complex business logic outside of the UI components, redux saga is integrated, ensuring a clear separation of concerns and improved maintainability. The front-end codebase follows a logical structure, organized into designated folders and functional modules, which enhances readability and scalability. Figure 4.3, the package diagram of the post service, outlines the systematic organization used within the platform. At the core of the post-service’s backend, there are two principal packages: com.vifrin.common and com.virgin.feign. The com.vifrin.common package is responsible for maintaining shared data types, constants, and other resources that need to be accessed broadly across different service modules, thereby promoting code reuse and consistency. Meanwhile, com.virgin.feign focuses on facilitating inter-service communication by handling API calls, setting it apart from packages dedicated to Kafka event processing.
