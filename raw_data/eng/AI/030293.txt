This paper introduces a novel object recognition method based on contour sparse representation utilizing Signed Distance Difference (SDD) features. The objective is to improve the accuracy and robustness of object recognition systems, particularly in scenarios with occlusions and variations in viewpoint. The proposed approach first extracts contour information from object images and then represents these contours using a sparse coding framework. SDD features, which capture both shape and spatial relationships, are employed to enhance the discriminative power of the representation. An efficient optimization algorithm is developed to solve the sparse coding problem. Experimental results on several benchmark datasets demonstrate that the proposed method achieves state-of-the-art performance compared to existing contour-based and feature-based object recognition techniques. The findings highlight the effectiveness of combining contour information with SDD features within a sparse representation framework for robust object recognition. This method offers significant potential for applications in computer vision, robotics, and image retrieval.

Keywords: Object Recognition, Contour Sparse Representation, Signed Distance Difference Features, SDD, Sparse Coding, Computer Vision.
