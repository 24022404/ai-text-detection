This paper introduces *StrObe*, a novel framework for real-time object detection directly from raw LiDAR data packets, eliminating the need for intermediate point cloud processing. The objective of this research is to address the latency and computational overhead associated with traditional LiDAR-based object detection pipelines, which often rely on full point cloud reconstruction before detection. *StrObe* leverages a lightweight, streaming-compatible neural network architecture that processes LiDAR packets incrementally as they are received, enabling early and continuous object detection. The proposed approach integrates a spatiotemporal feature extraction module to capture both spatial and temporal dependencies within the streaming data, ensuring robust detection accuracy. Experimental results on benchmark datasets demonstrate that *StrObe* achieves competitive detection performance while significantly reducing latency by up to 40% compared to conventional methods. Additionally, the framework exhibits scalability across different LiDAR configurations and environments, making it suitable for real-world applications such as autonomous driving and robotics. The key contribution of this work lies in its ability to perform object detection directly from streaming LiDAR data, offering a new paradigm for efficient and low-latency perception systems. Keywords: LiDAR, object detection, streaming data, real-time processing, autonomous systems, spatiotemporal modeling.
