Point cloud feature embedding is crucial for various 3D vision tasks. Multi-layer perceptrons (MLPs) offer a computationally efficient approach, but struggle with irregular data distributions inherent in point clouds. This paper introduces an Irregularly Tabulated MLP (IT-MLP) designed to accelerate point feature embedding. IT-MLP utilizes a novel tabulation strategy to pre-compute and store MLP outputs for frequently occurring input values, significantly reducing runtime computation. We propose an adaptive tabulation scheme that optimizes memory usage while maximizing performance gains. Experimental results on benchmark datasets demonstrate that IT-MLP achieves comparable or superior accuracy to standard MLPs with a substantial reduction in computational cost. Specifically, IT-MLP reduces the runtime by up to 40% compared to conventional MLP implementations, making it suitable for real-time 3D applications. IT-MLP offers a practical and efficient solution for point cloud processing, enhancing the speed and scalability of feature embedding.
Keywords: Point Cloud, Feature Embedding, MLP, Acceleration, 3D Vision, Irregular Data.
