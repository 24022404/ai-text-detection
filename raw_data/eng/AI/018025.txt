This paper introduces GIMP-ML, a novel collection of Python plugins designed to integrate state-of-the-art computer vision models directly into the GNU Image Manipulation Program (GIMP). GIMP-ML addresses the challenge of making complex AI-driven image processing techniques accessible to a broader audience, including artists and designers who may lack extensive programming expertise. The plugins leverage the GIMP Python API to provide a user-friendly interface for tasks such as image segmentation, object detection, style transfer, and image enhancement, utilizing pre-trained models from TensorFlow and PyTorch. Performance evaluations demonstrate that GIMP-ML enables users to perform sophisticated image manipulations with significantly reduced setup time and coding effort compared to traditional methods. GIMP-ML lowers the barrier to entry for utilizing computer vision within GIMP, fostering creative exploration and enhancing productivity for image editing workflows. Key words: GIMP, Python, computer vision, image processing, machine learning, plugins.
