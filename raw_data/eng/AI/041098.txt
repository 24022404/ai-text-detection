Monocular 3D object detection is a challenging task in computer vision, crucial for applications like autonomous driving and robotics. This paper introduces FCOS3D, a novel, fully convolutional, one-stage approach for monocular 3D object detection. Departing from previous anchor-based methods, FCOS3D leverages a per-pixel prediction strategy, directly regressing 3D bounding box parameters from each pixel on the feature map. This significantly reduces the number of design hyperparameters and simplifies the training process. Furthermore, we propose a centerness-based weighting strategy to suppress low-quality predictions and improve localization accuracy. Extensive experiments on the KITTI benchmark demonstrate that FCOS3D achieves state-of-the-art performance among monocular 3D object detectors, surpassing existing methods in both accuracy and efficiency. The proposed approach offers a simpler, more effective solution for monocular 3D object detection, paving the way for real-time and resource-constrained applications.
Keywords: Monocular 3D Object Detection, One-Stage Detector, Fully Convolutional Network, Autonomous Driving, Computer Vision.
