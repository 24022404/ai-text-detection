This paper addresses the challenge of model calibration in long-tailed object detection and instance segmentation, where the distribution of objects is imbalanced. The objective is to develop a calibration method that improves the accuracy and reliability of object detection models on tail classes. We propose a novel approach that combines a calibrated loss function with a class-balanced sampling strategy to mitigate the impact of class imbalance. Our method is evaluated on several benchmark datasets, including COCO and LVIS, and demonstrates significant improvements in calibration metrics, such as the expected calibration error, and in instance segmentation metrics, such as the average precision. The results show that our approach outperforms state-of-the-art methods, particularly on tail classes, and provides more accurate and reliable object detection and instance segmentation. The contributions of this research include a new perspective on model calibration for long-tailed object detection and instance segmentation, and a simple yet effective method for improving the accuracy and reliability of object detection models. Key keywords: model calibration, long-tailed object detection, instance segmentation, class imbalance, object detection models.
