This paper introduces TRACE, a novel framework for image search with text feedback, leveraging advanced visiolinguistic representations to enhance retrieval accuracy and user experience. The objective of this research is to address the limitations of existing image search systems, which often struggle to effectively incorporate textual feedback to refine search results. TRACE employs a three-step approach: Transform, Aggregate, and Compose. First, it transforms input images and textual feedback into high-dimensional embeddings using state-of-the-art vision and language models. Next, it aggregates these embeddings to capture the semantic relationships between visual and textual modalities. Finally, it composes these representations into a unified embedding space, enabling precise retrieval of images that align with the user’s textual feedback. Experimental results on benchmark datasets demonstrate that TRACE outperforms existing methods, achieving significant improvements in retrieval accuracy and robustness. The framework’s ability to dynamically adapt to user feedback makes it particularly suitable for real-world applications, such as e-commerce and multimedia retrieval. This work contributes to the field of visiolinguistic representation learning by introducing a scalable and efficient solution for image search with text feedback, paving the way for more intuitive and interactive search systems.  

**Keywords**: Visiolinguistic representations, image search, text feedback, multimodal learning, retrieval systems.
