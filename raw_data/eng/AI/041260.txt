3D object detection is crucial for autonomous driving, yet remains challenging due to the limitations of individual sensors. This paper introduces CLOCs, a novel Camera-LiDAR Object Candidates fusion framework designed to enhance 3D object detection performance. CLOCs leverages both 2D object proposals from camera images and 3D object candidates generated from LiDAR point clouds to create a comprehensive set of potential object locations. A graph-based fusion network is then employed to effectively integrate and reason over these multi-modal candidates, capturing the complementary information from both sensors. The network learns to refine object scores and bounding box parameters through message passing. Experimental results on the KITTI dataset demonstrate that CLOCs achieves state-of-the-art performance, significantly improving detection accuracy, particularly for objects that are difficult to detect using either sensor alone. The fusion strategy demonstrates robustness and offers a promising direction for multi-sensor fusion in autonomous driving perception systems. Keywords: 3D Object Detection, Camera-LiDAR Fusion, Autonomous Driving, Sensor Fusion, Deep Learning.
