This paper introduces Seglearn, a novel Python package designed to facilitate machine learning on sequence and time-series data. The primary objective of Seglearn is to provide a flexible and efficient framework for feature engineering, representation learning, and predictive modeling in temporal domains. Seglearn employs a segmented approach, enabling the creation of time-delay embedding features extracted from sliding windows, combined with end-to-end learning using integrated deep learning models. The package offers tools for time series segmentation, feature extraction (including statistical and frequency-based features), and model building based on scikit-learn and TensorFlow/Keras. Empirical evaluation demonstrates that Seglearn achieves competitive performance across various time series classification and regression tasks compared to state-of-the-art methods. Furthermore, the modular architecture of Seglearn allows for easy integration with existing data science workflows and supports the development of custom models and feature extractors. Seglearn simplifies the process of developing and deploying machine learning solutions for sequence data, offering a valuable resource for researchers and practitioners. Keywords: Time Series, Sequence Learning, Feature Engineering, Segmentation, Python Package, Machine Learning.
