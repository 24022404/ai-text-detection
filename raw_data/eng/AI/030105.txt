This paper presents a novel Human-In-The-Loop (HITL) approach for document layout analysis, aiming to bridge the gap between fully automated layout extraction and human accuracy. The increasing diversity and complexity of document formats pose significant challenges to traditional automated methods, often resulting in errors that require manual correction. Our proposed framework integrates machine learning-based layout detectors with interactive human feedback, enabling continuous model refinement and error correction in real time. By leveraging both automated detection algorithms and human expertise, the system dynamically identifies ambiguous or low-confidence regions, prompting targeted user input only when necessary. Experimental results demonstrate significant improvements in layout extraction accuracy, efficiency, and adaptability across various document types, including invoices, academic papers, and historical manuscripts. The results show that incorporating human input not only enhances model performance but also reduces the annotation effort compared to fully manual review. This hybrid methodology provides a practical solution for real-world applications where both precision and scalability are critical. The proposed HITL document layout analysis framework offers valuable insights for future development in intelligent document processing, adaptive annotation systems, and collaborative AI workflows. Keywords: human-in-the-loop, document layout analysis, machine learning, interactive annotation, document processing, hybrid systems.
