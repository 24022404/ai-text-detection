Context-aware object detection aims to improve object recognition by leveraging contextual information from the surrounding scene. This paper introduces a novel Layout Transfer Network (LTN) to explicitly model and transfer layout knowledge across different scenes, enhancing object detection performance. The LTN learns to predict scene layouts by encoding relationships between objects and transferring these learned layouts to guide object detection in new, unseen scenes. The network comprises a scene layout encoder, a layout transfer module, and a context-aware detection module. We evaluate our approach on challenging benchmark datasets, demonstrating that LTN significantly improves detection accuracy, particularly for objects with strong contextual dependencies. Experiments show that LTN outperforms existing context-aware object detection methods, achieving state-of-the-art results. The proposed method offers a robust framework for incorporating contextual information into object detection, with potential applications in autonomous driving and robotic perception. Keywords: Object Detection, Context Awareness, Scene Layout, Transfer Learning, Deep Learning.
