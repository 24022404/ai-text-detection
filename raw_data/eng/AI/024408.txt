Hyperspectral image (HSI) classification is a critical task in remote sensing, but it often faces challenges due to insufficient labeled data and class imbalance, which hinder model performance. This paper proposes a novel Spectral-Spatial-Dependent Global Learning (SSDGL) framework to address these issues effectively. The framework integrates spectral and spatial features through a dual-branch network, leveraging global dependencies to enhance feature representation. A spectral attention mechanism is introduced to prioritize informative spectral bands, while a spatial graph convolutional network captures contextual relationships among pixels. To tackle class imbalance, a dynamic loss function is designed to adjust weights based on class distribution. Experiments on benchmark HSI datasets demonstrate that SSDGL outperforms state-of-the-art methods, achieving significant improvements in classification accuracy, particularly for underrepresented classes. The proposed framework is robust, scalable, and applicable to real-world scenarios with limited labeled data. This research contributes to advancing HSI classification by providing a comprehensive solution for handling insufficient and imbalanced data, with potential applications in agriculture, environmental monitoring, and urban planning.  

**Keywords**: Hyperspectral image classification, spectral-spatial features, global learning, class imbalance, attention mechanism, graph convolutional network.
