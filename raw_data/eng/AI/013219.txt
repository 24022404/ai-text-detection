This paper investigates the application of the Sugeno integral, a mathematical aggregation operator, in the domain of machine learning for binary classification tasks. The study aims to explore the potential advantages of integrating the Sugeno integral in machine learning models to improve classification accuracy and decision-making processes.

Methods/Approach: We employed a methodological approach combining the Sugeno integral with traditional machine learning algorithms to create a hybrid classification framework. The study involved implementing this framework in various binary classification scenarios, testing its performance using diverse datasets. The framework's effectiveness was assessed by measuring classification accuracy and comparing it with conventional binary classification techniques.

Results/Findings: Our experimental results demonstrate that integrating the Sugeno integral enhances the classification performance of machine learning models. The proposed framework exhibited significant improvements in accuracy levels across multiple datasets compared to classical methods such as decision trees and support vector machines. Additionally, the integration allowed for more robust handling of uncertainty and imprecise information within the datasets.

Conclusion/Implications: This research provides novel insights into leveraging the Sugeno integral within machine learning models, particularly for binary classification tasks. The findings suggest that this approach not only enhances classification accuracy but also contributes to more reliable decision-making processes in the presence of uncertainty. These results pave the way for further exploration and applications of the Sugeno integral in other areas of machine learning and data science. Key keywords: Sugeno integral, binary classification, machine learning, aggregation operator, uncertainty management.
