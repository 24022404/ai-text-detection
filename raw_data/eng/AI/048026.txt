This paper introduces MeInGame, a novel approach for generating realistic and personalized game character faces from a single portrait image. Our method leverages a deep learning framework combining 3D Morphable Models (3DMMs) with generative adversarial networks (GANs) to reconstruct detailed facial geometry and textures. Specifically, we employ a two-stage process: first, a 3DMM fitting network estimates the initial facial shape and pose from the input portrait. Second, a GAN refines the facial details, enhancing realism and adapting the style to be suitable for integration into modern game engines. Experimental results demonstrate that MeInGame generates high-quality game character faces that closely resemble the input portrait while maintaining visual appeal within a game environment. User studies confirm the perceived similarity and aesthetic quality of the generated characters compared to existing methods. This work offers a practical and efficient solution for game developers and players to create personalized avatars, reducing the reliance on manual modeling and texturing processes. Keywords: game character generation, 3D face reconstruction, GAN, 3DMM, avatar creation, personalized avatars.
