This paper introduces a novel deep unsupervised learning framework for 3D point cloud processing, focusing on robust feature extraction through graph topology inference and filtering. The approach learns to construct an intrinsic graph structure directly from the point cloud data, simultaneously optimizing node embeddings and edge connections. A graph filtering module is then employed to refine the inferred graph, removing spurious connections and enhancing salient features. This allows the model to capture intricate geometric details and relationships within the 3D data without relying on manual annotation or prior knowledge. We demonstrate the effectiveness of our framework on benchmark datasets for 3D object classification and shape retrieval. Experimental results show that our method achieves competitive performance compared to existing unsupervised and semi-supervised techniques, highlighting its ability to learn meaningful representations from raw point clouds. The learned graph topology provides interpretable insights into the underlying structure of 3D shapes, offering a promising direction for unsupervised 3D data analysis.

Keywords: 3D Point Clouds, Unsupervised Learning, Graph Neural Networks, Graph Topology Inference, Geometric Feature Extraction, Deep Learning.
