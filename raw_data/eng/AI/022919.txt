Object detection systems typically require large amounts of annotated data and suffer when deployed in dynamic environments where new object classes emerge over time. This paper addresses the challenge of generalized and incremental few-shot object detection, aiming to build robust models that can recognize both previously seen and novel classes with minimal labeled examples. We propose a novel detection framework that integrates dynamic meta-learning with class-incremental adaptation strategies. Our approach leverages a prototype-based embedding to efficiently incorporate new object classes while preserving the detection performance on previously learned categories. We evaluate the framework on benchmark datasets, demonstrating superior performance over existing methods in terms of mean average precision (mAP) and class retention during incremental updates. Analysis shows the model’s capability to generalize from limited data while mitigating catastrophic forgetting. The proposed approach offers significant advancements for adaptive object detection in real-world applications, such as autonomous driving and intelligent surveillance systems, where continuous and efficient learning of new object classes is essential. Key keywords: few-shot object detection, incremental learning, meta-learning, prototype-based embedding, generalization, transfer learning.
