Novel view synthesis from a single image is a challenging problem in computer vision with applications in virtual reality and 3D modeling. This paper introduces a novel approach that leverages point cloud transformation to generate geometrically consistent and visually plausible novel views. Our method begins by estimating a sparse point cloud from the input image using a depth estimation network. This initial point cloud is then transformed into a canonical coordinate system. A novel point cloud rendering technique synthesizes the target view. A refinement network then refines the rendered image. Results on benchmark datasets demonstrate that our method achieves state-of-the-art performance, producing higher quality and more geometrically accurate novel views compared to existing approaches. The proposed approach offers improvements in handling occlusions and generating realistic details in challenging scenarios. The code will be publicly available.
**Keywords:** Novel View Synthesis, Single Image Reconstruction, Point Cloud Transformation, 3D Reconstruction, Computer Vision, Neural Rendering.
