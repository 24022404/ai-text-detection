Facial expression analysis is a fundamental task in computer vision with applications ranging from human-computer interaction to behavioral science. Existing methods typically address expression transfer, editing, and recognition as separate problems, often requiring specialized architectures and training procedures. This paper introduces an “All-In-One” network capable of simultaneously performing facial expression transfer, editing, and recognition using a unified framework. Our approach leverages a novel generative adversarial network (GAN) architecture incorporating expression-specific latent spaces and attention mechanisms. This allows for disentangled representation of facial features and expression attributes. The network is trained on a large-scale facial expression dataset using a multi-task learning objective. Experimental results demonstrate that our "All-In-One" network achieves state-of-the-art performance in facial expression transfer, outperforms existing methods in targeted expression editing, and maintains competitive accuracy in expression recognition, all within a single model. The proposed framework offers a more efficient and versatile solution for facial expression analysis, paving the way for real-time and interactive applications.

Keywords: Facial Expression, Expression Transfer, Expression Editing, Expression Recognition, Generative Adversarial Networks, Multi-task Learning.
