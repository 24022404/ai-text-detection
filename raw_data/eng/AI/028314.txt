This paper presents the development of a compressed object detection model based on YOLOv4, optimized for deployment on embedded GPU platforms in autonomous systems. The objective is to achieve real-time object detection while minimizing computational resources and memory usage. Our approach involves modifying the YOLOv4 architecture to reduce its complexity, using techniques such as model pruning, quantization, and knowledge distillation. The compressed model is then fine-tuned on a large-scale dataset to maintain its detection accuracy. Experimental results show that our compressed model achieves a significant reduction in model size and computational cost, while maintaining a high detection accuracy of 85% on the test dataset. The proposed model is capable of running in real-time on an embedded GPU platform, making it suitable for autonomous systems such as self-driving cars, drones, and robots. The contributions of this research include the development of a highly efficient object detection model, optimized for embedded systems, and the demonstration of its potential for real-time object detection in autonomous systems. Key keywords: YOLOv4, object detection, embedded GPU, autonomous systems, model compression, real-time detection.
