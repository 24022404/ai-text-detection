This paper introduces ReMix, a novel approach to addressing class imbalance in deep learning through calibrated resampling. The objective is to develop a method that can effectively handle imbalanced datasets, where one class has a significantly larger number of instances than others, leading to biased models. ReMix achieves this by employing a resampling strategy that adaptively adjusts the sampling rates for each class, ensuring that the model is exposed to a balanced representation of all classes during training. The approach utilizes a calibration mechanism to prevent overfitting to the majority class, while also preserving the underlying data distribution. Experimental results demonstrate that ReMix outperforms state-of-the-art class imbalance techniques, achieving improved accuracy and F1-scores on several benchmark datasets. The key contributions of this work include a calibrated resampling algorithm, an adaptive sampling rate adjustment mechanism, and a comprehensive evaluation framework for class imbalance methods. ReMix has significant implications for real-world applications, such as image classification, natural language processing, and medical diagnosis, where class imbalance is a common challenge. Keywords: class imbalance, deep learning, resampling, calibration, adaptive sampling.
