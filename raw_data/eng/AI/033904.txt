Salient object detection aims to identify and segment the most visually distinctive objects within an image. This paper introduces a novel Multi-scale Interactive Network (MINet) designed to improve the accuracy and robustness of salient object detection, particularly in complex scenes. Our approach leverages a multi-scale feature extraction module coupled with an interactive fusion mechanism. Specifically, we employ a hierarchical convolutional neural network to capture features at varying scales, enabling the model to understand both local details and global context. The interactive fusion module then selectively aggregates these multi-scale features, allowing for efficient information exchange and suppression of irrelevant background noise. Experimental results on several benchmark datasets demonstrate that MINet achieves state-of-the-art performance, outperforming existing methods in terms of precision, recall, and F-measure. The proposed network exhibits superior generalization capability and is more robust to challenging scenarios with cluttered backgrounds and complex object shapes. The code and trained models will be made publicly available. Keywords: Salient Object Detection, Deep Learning, Multi-scale Feature Fusion, Interactive Network, Computer Vision.
