This paper introduces a novel approach to automated code generation, specifically focusing on the creation of markup languages such as HTML and CSS. Our method, Neural Markup Generation with Visual Attention (NMG-VA), aims to bridge the gap between visual design and code by enabling machines to directly generate markup code from visual inputs. NMG-VA employs a deep neural network architecture incorporating a visual attention mechanism that selectively focuses on relevant features within the visual input, mimicking the way a human developer interprets a design. The model is trained end-to-end on a dataset of paired visual designs and corresponding markup code. Experimental results demonstrate that NMG-VA significantly outperforms existing methods in terms of code accuracy, structural correctness, and visual fidelity, particularly in generating complex layouts. The visual attention mechanism contributes to improved interpretability and allows the model to generalize to unseen designs more effectively. This research offers a promising avenue for automating web development tasks and facilitating design-to-code workflows.

Keywords: code generation, markup languages, visual attention, neural networks, automated web development.
