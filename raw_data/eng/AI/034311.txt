Abstract:

Scene text detection and recognition have seen significant advancements, yet understanding the relationships between detected text instances remains challenging, especially in complex visual environments. This paper introduces NENET, an Edge Learnable Network designed for efficient and accurate link prediction between scene text elements. The proposed network employs a graph-based representation, where detected text instances act as nodes and edges denote potential semantic or spatial relationships. NENET integrates both visual features and geometric cues through an attention-based edge learning mechanism that dynamically predicts linkage strength. Extensive experiments on benchmark scene text datasets demonstrate that NENET outperforms existing link prediction approaches, achieving higher precision and recall while maintaining low computational overhead suitable for real-time applications. Our analysis shows improved robustness in cluttered scenes and adaptability to different text layouts, facilitating downstream tasks such as text line grouping and end-to-end text understanding. The findings highlight NENET's potential for advancing scene text analysis in applications ranging from document digitization to augmented reality.  
Keywords: scene text, link prediction, graph neural network, edge learning, attention mechanism, text grouping, real-time processing.
